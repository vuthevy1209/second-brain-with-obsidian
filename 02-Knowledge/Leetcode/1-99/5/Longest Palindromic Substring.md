Given a string `s`, return _the longest_ _palindromic_ _substring_ in `s`.
<mark style="background:#d3f8b6">A string is **palindromic** if it reads the same forward and backward.</mark>

**Example 1:**

**Input:** s = "babad"
**Output:** "bab"
**Explanation:** "aba" is also a valid answer.

**Example 2:**

**Input:** s = "cbbd"
**Output:** "bb"

**Constraints:**

- `1 <= s.length <= 1000`
- `s` consist of only digits and English letters.
