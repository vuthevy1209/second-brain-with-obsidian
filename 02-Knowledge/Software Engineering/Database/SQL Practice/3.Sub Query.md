**Q41.** Cho biết những giáo viên có lương lớn nhất trong bộ môn của họ.

> _"Với mỗi giáo viên, kiểm tra xem lương của họ có lớn hơn hoặc bằng lương của TẤT CẢ giáo viên cùng bộ môn không?"_

```sql
SELECT GV.HOTEN, BM.TENBM
FROM GIAOVIEN GV 
    JOIN BOMON BM ON GV.MABM = BM.MABM
WHERE GV.LUONG >= ALL (
    SELECT GV2.LUONG
    FROM GIAOVIEN GV2
    WHERE GV2.MABM = GV.MABM
)
```

- O(n^2): Mỗi giáo với mỗi giáo viên ở bảng GV, sẽ chạy một lần sub query để lấy lương ở bảng giáo viên 2 sao cho GV2.MABM = GV.MABM.
- Tuy nhiên có thể SQL sẽ không ngu đến mức như vậy, nó có thể phân tích và parse ra một câu query tương đương nhưng tốt hơn:

```
Correlated Subquery (bạn viết)
        ↓  Query Optimizer phân tích
Execution Plan thực sự (có thể hoàn toàn khác)
```

```sql
-- Tương đương tối ưu hơn
SELECT GV.HOTEN, BM.TENBM
FROM GIAOVIEN GV
    JOIN BOMON BM ON GV.MABM = BM.MABM
    JOIN (
        SELECT MABM, MAX(LUONG) AS MAX_LUONG
        FROM GIAOVIEN
        GROUP BY MABM
    ) AS MAX_BM ON GV.MABM = MAX_BM.MABM 
               AND GV.LUONG = MAX_BM.MAX_LUONG
```

- Cách này chỉ **O(n)** — quét bảng 2 lần rồi JOIN.
