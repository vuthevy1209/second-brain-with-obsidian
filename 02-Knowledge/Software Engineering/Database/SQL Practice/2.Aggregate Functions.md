Q27. Cho biết số lượng giáo viên viên và tổng lương của họ.

```sql
SELECT COUNT(1), SUM(LUONG)
FROM GIAOVIEN
```

Q28. Cho biết số lượng giáo viên và lương trung bình của từng bộ môn.

```sql
SELECT BM.MABM, BM.TENBM, COUNT(1) AS SOLUONGGIAOVIEN, AVG(LUONG) LUONGTB
FROM GIAOVIEN GV
	JOIN BOMON BM ON GV.MABM = BM.MABM
GROUP BY BM.MABM
```

- Lưu ý lỗi tiềm ẩn: `BM.TENBM` có trong `SELECT` nhưng **không có trong `GROUP BY`** → một số DBMS (như SQL Server, PostgreSQL) sẽ **báo lỗi**. Nhưng MySQL chấp nhận.
```sql
	GROUP BY BM.MABM  -- ← chỉ GROUP BY mã, thiếu TENBM
```

Q29. Cho biết tên chủ đề và số lượng đề tài thuộc về chủ đề đó.

```sql
SELECT CD.MACD, CD.TENCD, COUNT(1) AS SOLUONGDETAI
FROM CHUDE CD 
	JOIN DETAI DT ON CD.MACD = DT.MACD
GROUP BY CD.MACD, CD.TENCD
```

Q30. Cho biết tên giáo viên và số lượng đề tài mà giáo viên đó tham gia.

```sql
SELECT GV.HOTEN, COUNT(DISTINCT MADT) AS SLDETAITHAMGIA
FROM GIAOVIEN GV
	JOIN THAMGIADETAI TGDT ON GV.MAGV = TGDT.MAGV
GROUP BY GV.MAGV, GV.HOTEN
```

Q31. Cho biết tên giáo viên và số lượng đề tài mà giáo viên đó làm chủ nhiệm.

```sql
SELECT GV.MAGV, GV.HOTEN, COUNT(DT.MADT) AS SOLUONGDETAICHUNHIEM
FROM GIAOVIEN GV
	JOIN DETAI DT ON GV.MAGV = DT.GVCNDT
GROUP BY GV.MAGV, GV.HOTEN
```
