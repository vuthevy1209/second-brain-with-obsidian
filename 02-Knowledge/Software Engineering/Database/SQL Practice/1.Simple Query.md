## Viết các câu truy vấn đơn giản

**Q1.** Cho biết họ tên và mức lương của các giáo viên nữ.

``` sql
SELECT MAGV, HOTEN, LUONG
FROM GIAOVIEN
WHERE PHAI = 'Nữ'
```

**Q2.** Cho biết họ tên của các giáo viên và lương của họ sau khi tăng 10%.

``` sql
SELECT MAGV, HOTEN, LUONG + LUONG * 0.1
FROM GIAOVIEN
```

**Q3.** Cho biết mã của các giáo viên có họ tên bắt đầu là "Nguyên" và lương trên $2000 hoặc, giáo viên là trưởng bộ môn nhận chức sau năm 1995.

- Sử dụng IN
``` sql
SELECT MAGV, HOTEN
FROM GIAOVIEN
WHERE (HOTEN LIKE 'Nguyen%' AND LUONG > 2000)
   OR (MAGV IN (
         SELECT TRUONGBM
         FROM BOMON
         WHERE YEAR(NGAYNHANCHUC) > 1995
   ));
```

- Sử dụng UNION
``` sql
SELECT MAGV 
FROM GIAOVIEN
WHERE (HOTEN LIKE 'Nguyen%' AND LUONG > 2000)
UNION
SELECT TRUONGBM
FROM BOMON
WHERE YEAR(NGAYNHANCHUC) > 1995
```

**Q4.** Cho biết tên những giáo viên khoa Công nghệ thông tin.

``` sql
SELECT GV.HOTEN
FROM GIAOVIEN GV 
	JOIN BOMON BM ON GV.MABM = BM.MABM
	JOIN KHOA K ON BM.MAKHOA = K.MAKHOA
WHERE K.TENKHOA = 'Cong nghe thong tin'
```

**Q9.** Cho biết các giáo viên của bộ môn "Vi sinh" có tham gia đề tài 006.

``` sql
SELECT GV.MAGV, GV.HOTEN
FROM GIAOVIEN GV 
    JOIN THAMGIADETAI TGDT ON GV.MAGV = TGDT.MAGV
    JOIN BOMON BM ON GV.MABM = BM.MABM

```

**Q10.** Với những đề tài thuộc cấp quản lý "Thành phố", cho biết mã đề tài, đề tài thuộc về chủ đề nào, họ tên người chủ nhiệm đề tài cùng với ngày sinh và địa chỉ của người ấy.

``` sql
SELECT DT.MADT, DT.TENDT, CD.TENCD, GV.HOTEN AS GIAOVIENCHUNHIEM
FROM DETAI DT 
	JOIN CHUDE CD ON DT.MACD = CD.MACD
	JOIN GIAOVIEN GV ON DT.GVCNDT = GV.MAGV

```

**Q19.** Tìm những giáo viên vừa là trưởng bộ môn vừa chủ nhiệm đề tài.

- **`IN` với `INTERSECT`** (không dùng được trong MySQL, chỉ dùng được trong SQL Server):
``` sql
SELECT *
FROM GIAOVIEN GV
WHERE GV.MAGV IN (
    SELECT TRUONGBM FROM BOMON
    INTERSECT
    SELECT GVCNDT FROM DETAI
);
```

- Dùng **`EXISTS`**
``` sql
SELECT *
FROM GIAOVIEN GV
WHERE EXISTS (SELECT 1 FROM BOMON WHERE TRUONGBM = GV.MAGV)
  AND EXISTS (SELECT 1 FROM DETAI WHERE GVCNDT = GV.MAGV);
```

- `IN` với subquery lồng nhau
```sql
SELECT *
FROM GIAOVIEN GV
WHERE GV.MAGV IN (SELECT TRUONGBM FROM BOMON)
  AND GV.MAGV IN (SELECT GVCNDT FROM DETAI);
```
