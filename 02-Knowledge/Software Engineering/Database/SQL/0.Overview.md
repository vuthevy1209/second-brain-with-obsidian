# SQL — Structured Query Language

**SQL** is the standard language used to communicate with relational databases (MySQL, PostgreSQL, SQL Server…). It allows you to **define structures**, **manipulate data**, and **query** information.

| Category                 | Purpose                     | Key Commands                                    | Note                             |     |
| ------------------------ | --------------------------- | ----------------------------------------------- | -------------------------------- | --- |
| **DDL**                  | Define database structure   | `CREATE`, `ALTER`, `DROP`, `TRUNCATE`           | [[1.Data Definition Language]]   |     |
| **DML**                  | Manipulate data             | `SELECT`, `INSERT`, `UPDATE`, `DELETE`          | [[2.Data Manipulation Language]] |     |
| **Filtering & Grouping** | Filter and sort results     | `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`       | [[3.Where, Group, Order]]        |     |
| **Aggregates**           | Summarize data              | `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`             | [[4.Aggregate-Functions]]        |     |
| **JOIN**                 | Combine multiple tables     | `INNER`, `LEFT`, `RIGHT`, `SELF`                | [[6.Join]]                       |     |
| **Subquery**             | Nested queries              | Subquery in `WHERE`, `FROM`, `SELECT`, `EXISTS` | [[7.Subquery]]                   |     |
| **Execution Order**      | How MySQL processes a query | `FROM → JOIN → WHERE → … → LIMIT`               | [[8.Execution-Order]]            |     |
