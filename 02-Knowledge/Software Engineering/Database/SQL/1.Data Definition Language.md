# DDL — Data Definition Language

**DDL** is used to **define and manage the structure** (schema) of a database — tables, columns, data types, and constraints. DDL statements are auto-committed (changes are permanent immediately).

| Command | Purpose |
|---|---|
| `CREATE` | Create a new table or database |
| `ALTER` | Modify an existing table |
| `DROP` | Permanently delete a table |
| `TRUNCATE` | Remove all rows but keep table structure |

---

## CREATE TABLE

Creates a new table with columns and constraints.

```sql
-- GIAOVIEN references BOMON (FK) and itself via GVQLCM (self-ref)
CREATE TABLE GIAOVIEN (
    MAGV     CHAR(4)      PRIMARY KEY,
    HOTEN    VARCHAR(40)  NOT NULL,
    LUONG    DECIMAL(8,2) CHECK (LUONG >= 0),
    PHAI     VARCHAR(3)   DEFAULT 'Nam',
    NGAYSINH DATE,
    DIACHI   VARCHAR(100),
    GVQLCM   CHAR(4),
    MABM     CHAR(4),
    FOREIGN KEY (GVQLCM) REFERENCES GIAOVIEN(MAGV),
    FOREIGN KEY (MABM)   REFERENCES BOMON(MABM)
);
```

**Key constraints used:**

| Constraint    | Meaning                                        | Example                                     |
| ------------- | ---------------------------------------------- | ------------------------------------------- |
| `PRIMARY KEY` | Unique identifier, cannot be NULL              | `MAGV CHAR(4) PRIMARY KEY`                  |
| `NOT NULL`    | Column must have a value                       | `HOTEN VARCHAR(40) NOT NULL`                |
| `DEFAULT`     | Provides a default value if none given         | `PHAI VARCHAR(3) DEFAULT 'Nam'`             |
| `CHECK`       | Enforces a condition on column values          | `CHECK (LUONG >= 0)`                        |
| `FOREIGN KEY` | Links column to a primary key in another table | `FOREIGN KEY (MABM) REFERENCES BOMON(MABM)` |

> [!NOTE]
> Build tables in **dependency order**: no-FK tables first (KHOA, CHUDE), then tables that reference them (BOMON, DETAI), and finally the most-dependent ones (GIAOVIEN, THAMGIADT).

## ALTER TABLE

Modifies an existing table — add/remove/rename columns, change data types.

```sql
ALTER TABLE GIAOVIEN ADD COLUMN EMAIL VARCHAR(100);
ALTER TABLE GIAOVIEN MODIFY COLUMN DIACHI VARCHAR(150);
ALTER TABLE GIAOVIEN RENAME COLUMN NGAYSINH TO DOB;
ALTER TABLE GIAOVIEN DROP COLUMN EMAIL;
```

## DROP vs TRUNCATE

```sql
DROP TABLE GV_DT;          -- removes structure + data (PERMANENT)
TRUNCATE TABLE THAMGIADT;  -- removes all rows, keeps structure
```

> [!WARNING]
> Both are **irreversible** without a backup. `DROP` deletes the table entirely; `TRUNCATE` only wipes the data.
