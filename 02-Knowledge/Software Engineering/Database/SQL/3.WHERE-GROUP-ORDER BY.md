## WHERE — Filter Rows

Filters **individual rows** before any grouping occurs.

```sql
-- Female lecturers in HTTT department, born after 1985, earning in range
SELECT HOTEN, LUONG, NGAYSINH
FROM GIAOVIEN
WHERE PHAI = 'Nữ'
  AND MABM = 'HTTT'
  AND NGAYSINH > '1985-12-31'
  AND LUONG BETWEEN 10000000 AND 20000000;
```

### Operators Reference

| Operator | Meaning | Example |
|---|---|---|
| `=` | Equals | `PHAI = 'Nữ'` |
| `<>` / `!=` | Not equals | `MABM <> 'HTTT'` |
| `>`, `<`, `>=`, `<=` | Comparisons | `LUONG >= 10000000` |
| `IN (...)` | Matches any value in list | `MABM IN ('HTTT', 'KHMT')` |
| `BETWEEN a AND b` | Within a range (inclusive) | `LUONG BETWEEN 10M AND 20M` |
| `LIKE` | Pattern match (`%` = wildcard) | `HOTEN LIKE 'Nguyễn%'` |
| `IS NULL` / `IS NOT NULL` | Check for NULL | `GVQLCM IS NULL` |
| `AND`, `OR`, `NOT` | Combine conditions | `PHAI = 'Nữ' AND LUONG > 15M` |

## GROUP BY — Group Rows

Collapses rows sharing the same value into one summary row. **Always used with aggregate functions.**

```sql
-- Headcount per department
SELECT MABM, COUNT(*) AS SO_GV
FROM GIAOVIEN
GROUP BY MABM;
```

## HAVING — Filter Groups

> Filters **after** `GROUP BY`. Use instead of `WHERE` when filtering on aggregate results.

```sql
-- Departments where average salary > 18 million (combine WHERE + HAVING)
SELECT MABM, COUNT(*) AS SO_GV_NU, AVG(LUONG) AS LUONG_TB
FROM GIAOVIEN
WHERE PHAI = 'Nữ'               -- ← filter rows first
GROUP BY MABM
HAVING AVG(LUONG) > 18000000;   -- ← then filter groups
```

> [!NOTE]
> `WHERE` filters rows **before** grouping. Therefore, aggregate functions cannot be used at WHERE. `HAVING` filters groups **after** grouping — so it can use aggregate functions like `COUNT(*)`, `AVG()`.

## ORDER BY — Sort Results

```sql
-- Sort by department, then salary descending within each dept
SELECT HOTEN, MABM, LUONG
FROM GIAOVIEN
ORDER BY MABM ASC, LUONG DESC;
```

## LIMIT — Restrict Result Count

```sql
-- page 2 = skip 5, take next 5
SELECT HOTEN, LUONG 
FROM GIAOVIEN
ORDER BY LUONG DESC
LIMIT 5 OFFSET 5;
```

- OFFSET = (số trang - 1) × kích thước trang 
- LIMIT = kích thước trang
