# DML — Data Manipulation Language

**DML** is used to **read and modify the actual data** inside tables. Unlike DDL, DML operations can be rolled back within a transaction.

## INSERT — Add New Rows

```sql
-- Insert a lecturer; parent tables (KHOA, BOMON) must already exist
INSERT INTO GIAOVIEN (MAGV, HOTEN, LUONG, PHAI, NGAYSINH, DIACHI, MABM)
VALUES ('GV01', 'Nguyễn Văn An', 15000000, 'Nam', '1980-05-15', 'TP.HCM', 'HTTT');
```

Always insert **parent** tables first. E.g. KHOA → BOMON → GIAOVIEN → THAMGIADT.

## SELECT — Query / Read Data

```sql
-- Specific columns with aliases
SELECT HOTEN AS 'Họ Tên', LUONG AS 'Lương Tháng'
FROM GIAOVIEN
WHERE PHAI = 'Nữ';
```

## UPDATE — Modify Existing Rows

```sql
-- Give all HTTT lecturers a 10% raise
UPDATE GIAOVIEN
SET LUONG = LUONG * 1.10
WHERE MABM = 'HTTT';
```

**Always use `WHERE` with `UPDATE`!** Omitting it modifies **every row** in the table.

## DELETE — Remove Rows

```sql
-- Delete child rows first, then the parent
DELETE FROM THAMGIADT WHERE MADT = 'DT99';
DELETE FROM CONGVIEC   WHERE MADT = 'DT99';
DELETE FROM DETAI      WHERE MADT = 'DT99';
```

**Always use `WHERE` with `DELETE`!** When FK constraints exist, delete **child rows first**, then the parent.
