# Set Operations — UNION, INTERSECT, EXCEPT

**Set operations** combine the result sets of two or more `SELECT` queries into a single result. Each query must return the **same number of columns** with **compatible data types**.

| Rule | Detail |
|------|--------|
| Same column count | Both `SELECT` statements must return the same number of columns |
| Compatible types | Column types must be compatible (e.g., `INT` with `INT`, `VARCHAR` with `VARCHAR`) |
| Column names | The result uses column names from the **first** `SELECT` |
| ORDER BY | Can only appear **once**, at the end of the entire statement |

---
## UNION (Phép hợp)

Combines rows from two result sets and **removes duplicates** automatically.

```sql
SELECT *
FROM GIAOVIEN GVNam
WHERE GVNam.PHAI = 'Nam'
UNION
SELECT *
FROM GIAOVIEN GVNu
WHERE GVNu.PHAI = 'Nữ'
```

### UNION ALL

Keeps **all rows including duplicates** — faster than `UNION` since it skips deduplication.

```sql
-- All lecturers and teaching assistants in one list
SELECT MAGV AS ID, HOTEN AS NAME, 'Lecturer' AS ROLE
FROM GIAOVIEN
UNION
SELECT MATG AS ID, HOTEN AS NAME, 'Teaching Assistant' AS ROLE
FROM TROGIANG;
```

**When to use `UNION ALL`?**
<mark style="background:#d3f8b6">Use it when you know there are no duplicates, or when you intentionally want duplicates. It avoids the overhead of sorting and deduplication.</mark>

## INTERSECT (Phép giao)

Returns only rows that appear in **both** result sets (the intersection).

```sql
-- Students who enrolled in both course CS101 and CS201
SELECT MASV FROM DANGKY WHERE MAMH = 'CS101'
INTERSECT
SELECT MASV FROM DANGKY WHERE MAMH = 'CS201';
```

**MySQL does not natively support `INTERSECT`** (added in MySQL 8.0.31). For older versions, use `INNER JOIN` or `IN` as a workaround.

- Workaround for older MySQL (using IN)

```sql
-- Students who enrolled in both CS101 and CS201
SELECT DISTINCT MASV FROM DANGKY
WHERE MAMH = 'CS101'
  AND MASV IN (SELECT MASV FROM DANGKY WHERE MAMH = 'CS201');
```

- Workaround using INNER JOIN
```sql
SELECT DISTINCT d1.MASV
FROM DANGKY d1
INNER JOIN DANGKY d2 ON d1.MASV = d2.MASV
WHERE d1.MAMH = 'CS101' AND d2.MAMH = 'CS201';
```

## EXCEPT (Phép trừ)

Returns rows from the **first** result set that do **not** appear in the second — the difference.

```sql
-- Lecturers who have NOT been assigned to any department
SELECT MAGV FROM GIAOVIEN
EXCEPT
SELECT MAGV FROM PHANCONG;
```

**MySQL does not natively support `EXCEPT`** (added in MySQL 8.0.31). Oracle uses `MINUS` instead. For older MySQL, use `NOT IN` or `LEFT JOIN ... WHERE NULL` as a workaround.

- Workaround for older MySQL (using NOT IN)
```sql
-- Lecturers who have NOT been assigned to any department
SELECT DISTINCT MAGV FROM GIAOVIEN
WHERE MAGV NOT IN (SELECT MAGV FROM PHANCONG);
```

- Workaround using LEFT JOIN
```sql
SELECT DISTINCT gv.MAGV
FROM GIAOVIEN gv
LEFT JOIN PHANCONG pc ON gv.MAGV = pc.MAGV
WHERE pc.MAGV IS NULL;
```
