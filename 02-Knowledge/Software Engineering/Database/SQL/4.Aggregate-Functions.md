# Aggregate Functions

Aggregate functions **compute a single result from a set of rows**. They summarize data and are almost always used with `GROUP BY`.

| Function     | Returns                               |
| ------------ | ------------------------------------- |
| `COUNT(*)`   | Number of rows (including NULLs)      |
| `COUNT(col)` | Number of non-NULL values in a column |
| `SUM(col)`   | Total sum of values                   |
| `AVG(col)`   | Average of values                     |
| `MAX(col)`   | Maximum value                         |
| `MIN(col)`   | Minimum value                         |

```sql
-- Full stats per department: count, total, avg, max, min salary
SELECT
    MABM,
    COUNT(*)   AS SO_GV,
    SUM(LUONG) AS TONG_LUONG,
    AVG(LUONG) AS LUONG_TB,
    MAX(LUONG) AS CAO_NHAT,
    MIN(LUONG) AS THAP_NHAT
FROM GIAOVIEN
GROUP BY MABM;
```

**Sample Result:**

| MABM | SO_GV | TONG_LUONG | LUONG_TB | CAO_NHAT | THAP_NHAT |
|---|---|---|---|---|---|
| HTTT | 5 | 80,000,000 | 16,000,000 | 22,000,000 | 10,000,000 |
| KHMT | 4 | 72,000,000 | 18,000,000 | 25,000,000 | 12,000,000 |

## With HAVING

```sql
-- Only departments where average salary > 15 million
SELECT MABM, AVG(LUONG) AS LUONG_TB
FROM GIAOVIEN
GROUP BY MABM
HAVING AVG(LUONG) > 15000000;
```

## COUNT(*) vs COUNT(col)

```sql
-- COUNT(*) includes NULLs; COUNT(col) skips NULLs
SELECT
    COUNT(*)      AS TONG_ROWS,       -- all lecturers
    COUNT(GVQLCM) AS CO_GVCM,         -- lecturers WITH a supervisor
    COUNT(*) - COUNT(GVQLCM) AS KHONG_CO_GVCM
FROM GIAOVIEN;
```

> [!NOTE]
> `COUNT(GVQLCM)` counts only rows where `GVQLCM` is **not NULL** — useful for detecting optional/missing relationships.
