# JOIN — Combining Tables

`JOIN` merges rows from two or more tables based on a **related column** (usually a foreign key). Instead of duplicating data, you store it once and join it as needed.

---
## INNER JOIN

Returns rows where the condition matches **in both tables**. Unmatched rows are excluded.

```sql
-- Lecturer → Department → Faculty (3-table chain)
SELECT gv.HOTEN, bm.TENBM, k.TENKHOA
FROM GIAOVIEN gv
INNER JOIN BOMON bm ON gv.MABM = bm.MABM
INNER JOIN KHOA  k  ON bm.MAKHOA = k.MAKHOA;
```

```sql
-- Hai câu này hoàn toàn giống nhau:
SELECT * FROM A JOIN B ON A.id = B.id;
SELECT * FROM A INNER JOIN B ON A.id = B.id;
```

`INNER` chỉ là từ khóa **tùy chọn**, viết hay không viết kết quả như nhau. Hầu hết mọi người bỏ `INNER` cho ngắn gọn.

## LEFT JOIN

Returns **all rows from the left table**. Unmatched right-side columns are `NULL`.

```sql
-- All lecturers, even those with no department
SELECT gv.HOTEN, bm.TENBM
FROM GIAOVIEN gv
LEFT JOIN BOMON bm ON gv.MABM = bm.MABM;
```

## RIGHT JOIN

Returns **all rows from the right table**. Unmatched left-side columns are `NULL`.

```sql
-- All departments, even if they have no lecturers
SELECT gv.HOTEN, bm.TENBM
FROM GIAOVIEN gv
RIGHT JOIN BOMON bm ON gv.MABM = bm.MABM;
```

## FULL OUTER JOIN

Returns **all rows from both tables**. MySQL doesn't support FULL OUTER JOIN natively.

```sql
SELECT gv.HOTEN, bm.TENBM
FROM GIAOVIEN gv LEFT JOIN BOMON bm ON gv.MABM = bm.MABM
UNION
SELECT gv.HOTEN, bm.TENBM
FROM GIAOVIEN gv RIGHT JOIN BOMON bm ON gv.MABM = bm.MABM;
```

## Self JOIN
Used when rows reference other rows in the **same table** (e.g., `GVQLCM` = supervisor is also a `GIAOVIEN`).

```sql
-- Each lecturer with their supervisor's name (GVQLCM → MAGV)
SELECT gv.HOTEN AS GV, sup.HOTEN AS GIAM_SAT
FROM GIAOVIEN gv
LEFT JOIN GIAOVIEN sup ON gv.GVQLCM = sup.MAGV;
```
