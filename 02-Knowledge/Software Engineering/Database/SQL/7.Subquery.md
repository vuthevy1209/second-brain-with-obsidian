## Subquery in WHERE — Scalar (returns one value)

```sql
-- Lecturers earning above the overall average
SELECT HOTEN, LUONG
FROM GIAOVIEN
WHERE LUONG > (SELECT AVG(LUONG) FROM GIAOVIEN);
--             └── ① runs first → e.g. 16,500,000
--  ② outer: WHERE LUONG > 16500000
```

## Subquery in WHERE — with IN (returns a list)

```sql
-- Lecturers who have participated in at least one research project
SELECT HOTEN
FROM GIAOVIEN
WHERE MAGV IN (SELECT DISTINCT MAGV FROM THAMGIADT);
```

## Subquery in FROM (Derived Table)

Creates a **temporary table** that the outer query treats like a real table.

```sql
-- Departments where average salary > 18 million
SELECT dept_stats.MABM, dept_stats.LUONG_TB
FROM (
    SELECT MABM, AVG(LUONG) AS LUONG_TB
    FROM GIAOVIEN
    GROUP BY MABM
) AS dept_stats                          -- alias is REQUIRED in MySQL
WHERE dept_stats.LUONG_TB > 18000000;
```

## Subquery in SELECT (Scalar Subquery)

> Returns one value, evaluated for **every row** of the outer query.

```sql
-- Each lecturer's salary vs. company average
SELECT
    HOTEN,
    LUONG,
    (SELECT AVG(LUONG) FROM GIAOVIEN)         AS LUONG_TB,
    LUONG - (SELECT AVG(LUONG) FROM GIAOVIEN) AS CHENH_LECH
FROM GIAOVIEN;
```

| HOTEN | LUONG | LUONG_TB | CHENH_LECH |
|---|---|---|---|
| Nguyễn Văn An | 15,000,000 | 16,500,000 | -1,500,000 |
| Trần Thị Bình | 22,000,000 | 16,500,000 | +5,500,000 |

## EXISTS / NOT EXISTS

Checks whether the subquery returns **any rows** — stops as soon as one is found (short-circuit).

```sql
-- Departments with at least one lecturer / with NO lecturers
SELECT TENBM FROM BOMON bm
WHERE EXISTS (
    SELECT 1 FROM GIAOVIEN gv WHERE gv.MABM = bm.MABM
);

SELECT TENBM FROM BOMON bm
WHERE NOT EXISTS (
    SELECT 1 FROM GIAOVIEN gv WHERE gv.MABM = bm.MABM
);
```

> [!NOTE]
> `SELECT 1` is a convention — we only care whether rows exist, not their content. These are **correlated subqueries**: the inner query references the outer query's row and re-evaluates for each.
