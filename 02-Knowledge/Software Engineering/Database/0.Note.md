## 1. COUNT(1) VS COUNT(\*)

#### Về mặt kết quả → **Hoàn toàn giống nhau**

Cả hai đều đếm **số dòng** trong nhóm, không quan tâm giá trị cột. Với DBMS hiện đại thì hiệu suất là như nhau.

```sql
SELECT COUNT(1) FROM GIAOVIEN   -- kết quả: 10
SELECT COUNT(*) FROM GIAOVIEN   -- kết quả: 10  ✓ giống nhau
```

- Dùng **`COUNT(*)`** → chuẩn SQL, rõ ý nghĩa hơn, được khuyến nghị
- Dùng **`COUNT(1)`** → một số người quen viết, hoàn toàn chấp nhận được
- Dùng **`COUNT(column)`** → khi muốn đếm **loại trừ NULL**

# 2. Lấy giá trị lớn thứ 2

#### Cách 1: Dùng `LIMIT + OFFSET` _(đơn giản nhất)_

```sql
SELECT LUONG
FROM GIAOVIEN
ORDER BY LUONG DESC
LIMIT 1 OFFSET 1  -- bỏ qua 1 cái đầu, lấy cái thứ 2
```

> Nếu có **2 người cùng lương cao nhất** → kết quả sai

#### Cách 2: Dùng Subquery _(xử lý được trùng lặp)_

```sql
SELECT MAX(LUONG)
FROM GIAOVIEN
WHERE LUONG < (
    SELECT MAX(LUONG)  -- loại bỏ giá trị max thứ 1
    FROM GIAOVIEN
)
```

> Không bị ảnh hưởng bởi dữ liệu trùng

#### Cách 3: Dùng `DENSE_RANK()` _(chuẩn nhất)_

```sql
SELECT HOTEN, LUONG
FROM (
    SELECT HOTEN, LUONG,
           DENSE_RANK() OVER (ORDER BY LUONG DESC) AS xep_hang
    FROM GIAOVIEN
) AS ranked
WHERE xep_hang = 2  -- đổi số này để lấy top N bất kỳ
```
