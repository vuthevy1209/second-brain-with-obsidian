# Java 8 Features

## Overview

Java 8 (released March 2014) was the most significant Java release in years, introducing functional programming capabilities alongside the traditional OOP model. Key features:

- Lambda Expressions
- Functional Interfaces
- Stream API
- Optional
- Default and Static Interface Methods
- Method References
- New Date/Time API (`java.time`)
- `CompletableFuture`
- Collectors

## Lambda Expressions

A **lambda** is an anonymous function — a concise way to represent a block of code as data.

**Syntax**: `(parameters) -> body`

```java
// Before Java 8
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello");
    }
};

// Java 8 lambda
Runnable r = () -> System.out.println("Hello");

// With parameters
Comparator<String> comp = (a, b) -> a.compareTo(b);

// With block body
Comparator<Integer> comp2 = (a, b) -> {
    if (a == b) return 0;
    return a > b ? 1 : -1;
};

// Single param — parentheses optional
Consumer<String> print = s -> System.out.println(s);
```

## Functional Interfaces

A **functional interface** has exactly one abstract method. Lambdas implement functional interfaces.

The `@FunctionalInterface` annotation enforces this contract at compile time.

### Built-in Functional Interfaces (`java.util.function`)

| Interface | Signature | Description |
|-----------|-----------|-------------|
| `Predicate<T>` | `boolean test(T t)` | Test a condition |
| `Function<T, R>` | `R apply(T t)` | Transform T → R |
| `Consumer<T>` | `void accept(T t)` | Consume without return |
| `Supplier<T>` | `T get()` | Supply a value |
| `BiFunction<T, U, R>` | `R apply(T t, U u)` | Two inputs, one output |
| `BiConsumer<T, U>` | `void accept(T t, U u)` | Two inputs, no output |
| `BiPredicate<T, U>` | `boolean test(T t, U u)` | Two inputs, boolean |
| `UnaryOperator<T>` | `T apply(T t)` | `Function<T, T>` |
| `BinaryOperator<T>` | `T apply(T t1, T t2)` | `BiFunction<T, T, T>` |

```java
Predicate<Integer> isEven = n -> n % 2 == 0;
isEven.test(4);         // true
isEven.negate();        // Predicate: n % 2 != 0
isEven.and(n -> n > 0); // compound predicate

Function<String, Integer> toLength = String::length;
toLength.apply("hello"); // 5
toLength.andThen(n -> n * 2).apply("hello"); // 10

Consumer<String> log = System.out::println;
log.accept("message");

Supplier<List<String>> listFactory = ArrayList::new;
List<String> list = listFactory.get();
```

## Method References

A shorthand for lambdas that just call an existing method.

| Type | Syntax | Equivalent Lambda |
|------|--------|-------------------|
| Static method | `ClassName::staticMethod` | `(args) -> ClassName.staticMethod(args)` |
| Instance method (specific) | `instance::method` | `(args) -> instance.method(args)` |
| Instance method (arbitrary) | `ClassName::instanceMethod` | `(obj, args) -> obj.instanceMethod(args)` |
| Constructor | `ClassName::new` | `(args) -> new ClassName(args)` |

```java
// Static method reference
Function<String, Integer> parse = Integer::parseInt;

// Instance method on a specific object
String prefix = "Hello, ";
Function<String, String> greet = prefix::concat;

// Instance method on an arbitrary object of a type
Function<String, String> upper = String::toUpperCase;
Comparator<String> compare = String::compareTo;

// Constructor reference
Supplier<ArrayList<String>> listMaker = ArrayList::new;
Function<String, StringBuilder> sbMaker = StringBuilder::new;
```

## Stream API

Streams represent a **pipeline of operations** on a sequence of elements. They are:
- **Lazy**: intermediate operations are not executed until a terminal operation is invoked
- **Non-mutating**: the source collection is not modified
- **Possibly parallel**: easy parallelization with `.parallelStream()`

### Creating Streams

```java
// From Collection
List<String> names = List.of("Alice", "Bob", "Charlie");
Stream<String> stream = names.stream();

// From array
Stream<String> arrStream = Arrays.stream(new String[]{"a", "b"});

// From values
Stream<Integer> of = Stream.of(1, 2, 3);

// Infinite streams
Stream<Integer> naturals = Stream.iterate(0, n -> n + 1);
Stream<Double> randoms = Stream.generate(Math::random);

// Range (IntStream, LongStream, DoubleStream)
IntStream range = IntStream.range(0, 10);       // 0..9
IntStream rangeClosed = IntStream.rangeClosed(1, 10); // 1..10
```

### Intermediate Operations (lazy, return Stream)

```java
Stream<String> stream = names.stream()
    .filter(s -> s.startsWith("A"))      // Predicate<T>
    .map(String::toUpperCase)            // Function<T, R>
    .flatMap(s -> Stream.of(s.split("")))// Function<T, Stream<R>>
    .distinct()                          // removes duplicates
    .sorted()                            // natural order
    .sorted(Comparator.reverseOrder())   // custom order
    .peek(System.out::println)           // debug without consuming
    .limit(5)                            // max 5 elements
    .skip(2);                            // skip first 2
```

### Terminal Operations (eager, trigger pipeline)

```java
List<String> names = List.of("Alice", "Bob", "Charlie", "Anna");

// Collection
List<String> result = names.stream().collect(Collectors.toList());
Set<String> set = names.stream().collect(Collectors.toSet());

// Reduce
Optional<String> first = names.stream().filter(s -> s.startsWith("A")).findFirst();
Optional<String> any = names.stream().findAny(); // for parallel

long count = names.stream().filter(s -> s.length() > 3).count();
Optional<String> min = names.stream().min(Comparator.naturalOrder());
Optional<String> max = names.stream().max(Comparator.naturalOrder());

boolean allMatch = names.stream().allMatch(s -> s.length() > 0);  // true
boolean anyMatch = names.stream().anyMatch(s -> s.startsWith("A")); // true
boolean noneMatch = names.stream().noneMatch(s -> s.isEmpty());    // true

// forEach
names.stream().forEach(System.out::println);

// Reduce
int sum = IntStream.of(1,2,3,4,5).reduce(0, Integer::sum);
Optional<Integer> product = Stream.of(1,2,3).reduce((a, b) -> a * b);

// toArray
Object[] arr = names.stream().toArray();
String[] strArr = names.stream().toArray(String[]::new);
```

### Collectors

```java
import java.util.stream.Collectors;

List<String> names = List.of("Alice", "Bob", "Charlie", "Anna", "Bill");

// Joining
String joined = names.stream().collect(Collectors.joining(", "));    // "Alice, Bob, ..."
String wrapped = names.stream().collect(Collectors.joining(", ", "[", "]")); // "[Alice, Bob, ...]"

// Grouping
Map<Integer, List<String>> byLength = names.stream()
    .collect(Collectors.groupingBy(String::length));
// {5=[Alice, Charlie], 3=[Bob, Anna, Bill]}... wait: Anna=4, Bill=4

// Counting per group
Map<Integer, Long> countByLength = names.stream()
    .collect(Collectors.groupingBy(String::length, Collectors.counting()));

// Partitioning (binary grouping by predicate)
Map<Boolean, List<String>> partitioned = names.stream()
    .collect(Collectors.partitioningBy(s -> s.startsWith("A")));
// {true=[Alice, Anna], false=[Bob, Charlie, Bill]}

// Statistics
IntSummaryStatistics stats = names.stream()
    .collect(Collectors.summarizingInt(String::length));
stats.getCount(); stats.getSum(); stats.getMin(); stats.getMax(); stats.getAverage();

// toMap
Map<String, Integer> nameLengths = names.stream()
    .collect(Collectors.toMap(s -> s, String::length));

// Unmodifiable collectors (Java 10+)
List<String> immutable = names.stream().collect(Collectors.toUnmodifiableList());
```

### Numeric Streams

```java
int[] numbers = {1, 2, 3, 4, 5};
IntStream intStream = Arrays.stream(numbers);

intStream.sum();      // 15
intStream.average();  // OptionalDouble{3.0}
intStream.min();      // OptionalInt{1}
intStream.max();      // OptionalInt{5}

// mapToInt — convert to IntStream for numeric ops
OptionalDouble avg = names.stream()
    .mapToInt(String::length)
    .average();
```

## Optional

`Optional<T>` is a container that may or may not hold a non-null value. It avoids `NullPointerException` and makes null-handling explicit.

```java
// Creating
Optional<String> opt = Optional.of("hello");       // throws NPE if null
Optional<String> nullable = Optional.ofNullable(null); // empty if null
Optional<String> empty = Optional.empty();

// Checking and getting
opt.isPresent();       // true
opt.isEmpty();         // false (Java 11+)
opt.get();             // "hello" (throws if empty)
opt.orElse("default"); // "hello" (returns default if empty)
opt.orElseGet(() -> computeDefault()); // lazy default
opt.orElseThrow(() -> new IllegalStateException("Not found"));

// Transforming
opt.map(String::toUpperCase);         // Optional<String> with "HELLO"
opt.flatMap(s -> findByName(s));      // for methods returning Optional
opt.filter(s -> s.startsWith("h"));  // Optional with value if predicate matches

// Consuming
opt.ifPresent(System.out::println);
opt.ifPresentOrElse(                  // Java 9+
    s -> System.out.println("Found: " + s),
    () -> System.out.println("Not found")
);
```

## Default and Static Interface Methods

Java 8 allows interfaces to have method implementations:

```java
interface Vehicle {
    String getType();

    // Default method — provides a default implementation
    default String describe() {
        return "This is a " + getType();
    }

    // Static method — utility on the interface itself
    static Vehicle create(String type) {
        return () -> type;
    }
}

class Car implements Vehicle {
    @Override
    public String getType() { return "Car"; }
    // describe() is inherited with default behavior
}
```

## New Date/Time API (`java.time`)

Replaces the broken `java.util.Date` and `java.util.Calendar`.

```java
// Immutable date/time objects
LocalDate date = LocalDate.now();                  // 2024-01-15
LocalDate specific = LocalDate.of(2024, 1, 15);
LocalDate parsed = LocalDate.parse("2024-01-15");

LocalTime time = LocalTime.now();                  // 14:30:00
LocalTime specific2 = LocalTime.of(14, 30, 0);

LocalDateTime dateTime = LocalDateTime.now();
LocalDateTime combined = LocalDateTime.of(date, time);

ZonedDateTime zoned = ZonedDateTime.now(ZoneId.of("Asia/Ho_Chi_Minh"));

// Manipulation (returns new object — immutable)
date.plusDays(7)
    .plusMonths(1)
    .minusYears(1)
    .withDayOfMonth(1);

// Comparison
date.isBefore(LocalDate.now());
date.isAfter(LocalDate.now());
date.isEqual(LocalDate.now());

// Extraction
date.getYear();
date.getMonth();          // JANUARY
date.getMonthValue();     // 1
date.getDayOfMonth();     // 15
date.getDayOfWeek();      // MONDAY

// Periods and Durations
Period period = Period.between(LocalDate.of(2020, 1, 1), LocalDate.now());
period.getYears(); period.getMonths(); period.getDays();

Duration duration = Duration.between(LocalTime.of(9, 0), LocalTime.of(17, 0));
duration.toHours(); // 8

// Formatting
DateTimeFormatter fmt = DateTimeFormatter.ofPattern("dd/MM/yyyy");
String formatted = date.format(fmt);
LocalDate parsed2 = LocalDate.parse("15/01/2024", fmt);
```

## `CompletableFuture`

Enables **asynchronous, non-blocking** programming with chaining:

```java
// Async computation
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
    Thread.sleep(1000);
    return "result";
});

// Chaining
future
    .thenApply(String::toUpperCase)           // transform result
    .thenAccept(System.out::println)          // consume result
    .thenRun(() -> System.out.println("Done")); // run after

// Combining futures
CompletableFuture<String> f1 = CompletableFuture.supplyAsync(() -> "Hello");
CompletableFuture<String> f2 = CompletableFuture.supplyAsync(() -> "World");

CompletableFuture<String> combined = f1.thenCombine(f2, (a, b) -> a + " " + b);

// Wait for all
CompletableFuture.allOf(f1, f2).join();

// Wait for first
CompletableFuture.anyOf(f1, f2).join();

// Exception handling
future
    .exceptionally(e -> "fallback")
    .handle((result, error) -> error != null ? "error" : result);
```
