# Java String

## What is a String?

`String` is an **immutable**, `final` class in `java.lang`. Every String object, once created, cannot be changed. Operations that appear to modify a String actually create a new String object.

```java
String s = "hello";
s.toUpperCase(); // does NOT modify s
System.out.println(s); // still "hello"

String upper = s.toUpperCase(); // creates a new String
System.out.println(upper); // "HELLO"
```

## String Pool (Interning)

Java maintains a **String Pool** (part of the heap's metaspace) to optimize memory by reusing common string literals.

```java
String a = "hello";      // stored in String pool
String b = "hello";      // reuses same object from pool
String c = new String("hello"); // forces a new heap object (avoid this)

System.out.println(a == b);      // true  (same pool reference)
System.out.println(a == c);      // false (different object)
System.out.println(a.equals(c)); // true  (same content)
```

Always use `.equals()` to compare String content, never `==`.

## Creating Strings

```java
String s1 = "literal";                    // from pool
String s2 = new String("object");         // new heap object
String s3 = String.valueOf(42);           // from primitive
String s4 = String.valueOf(true);
String s5 = new StringBuilder("build").toString();
String s6 = String.format("Name: %s, Age: %d", "Alice", 30);
```

## Common String Methods

### Inspection

```java
String s = "Hello, World!";

s.length()                  // 13
s.isEmpty()                 // false
s.isBlank()                 // false (Java 11+: checks whitespace only)
s.charAt(0)                 // 'H'
s.indexOf('o')              // 4
s.lastIndexOf('o')          // 8
s.contains("World")         // true
s.startsWith("Hello")       // true
s.endsWith("!")             // true
s.matches("[A-Za-z, !]+")   // true (regex)
```

### Transformation

```java
String s = "  Hello, World!  ";

s.toUpperCase()             // "  HELLO, WORLD!  "
s.toLowerCase()             // "  hello, world!  "
s.trim()                    // "Hello, World!"  (removes leading/trailing spaces)
s.strip()                   // "Hello, World!"  (Unicode-aware, Java 11+)
s.stripLeading()            // "Hello, World!  "
s.stripTrailing()           // "  Hello, World!"
s.replace('l', 'L')         // "  HeLLo, WorLd!  "
s.replace("World", "Java")  // "  Hello, Java!  "
s.replaceAll("\\s+", "_")   // replaces whitespace with _ (regex)
s.replaceFirst("\\s", "-")  // replaces first whitespace
```

### Splitting and Joining

```java
String csv = "a,b,c,d";
String[] parts = csv.split(",");      // ["a", "b", "c", "d"]
String[] twoparts = csv.split(",", 2); // ["a", "b,c,d"]

String joined = String.join("-", "a", "b", "c"); // "a-b-c"
String joined2 = String.join(", ", parts);        // "a, b, c, d"
```

### Substrings

```java
String s = "Hello, World!";
s.substring(7)     // "World!"
s.substring(7, 12) // "World"
```

### Comparison

```java
String a = "hello";
String b = "HELLO";

a.equals(b)                 // false
a.equalsIgnoreCase(b)       // true
a.compareTo(b)              // positive (lexicographic: 'h' > 'H')
a.compareToIgnoreCase(b)    // 0 (equal)
```

### Conversion

```java
"123".toCharArray()         // ['1', '2', '3']
String.valueOf(new char[]{'H','i'}) // "Hi"
"  hello  ".strip()         // "hello"
```

## String Formatting (Java 13+: Text Blocks)

```java
// String.format
String msg = String.format("Name: %s | Age: %d | Score: %.2f", "Alice", 25, 98.5);

// Text Blocks (Java 15+, preview in 13-14)
String json = """
        {
            "name": "Alice",
            "age": 25
        }
        """;

// formatted() — text block companion
String html = """
        <p>%s</p>
        """.formatted("Hello");
```

## String.format Specifiers

| Specifier | Type | Example |
|-----------|------|---------|
| `%s` | String | `"hello"` |
| `%d` | Integer | `42` |
| `%f` | Float/Double | `3.140000` |
| `%.2f` | 2 decimal places | `3.14` |
| `%n` | Newline (platform-safe) | |
| `%b` | Boolean | `true` |
| `%c` | Character | `'A'` |
| `%x` | Hex integer | `ff` |
| `%10s` | Right-padded to 10 chars | |
| `%-10s` | Left-padded to 10 chars | |

## StringBuilder vs StringBuffer

`String` is immutable. For repeated modifications, use `StringBuilder` (not thread-safe, faster) or `StringBuffer` (thread-safe).

```java
StringBuilder sb = new StringBuilder();
sb.append("Hello");
sb.append(", ");
sb.append("World");
sb.insert(5, "!");          // "Hello!, World"
sb.delete(5, 6);            // "Hello, World"
sb.reverse();               // "dlroW ,olleH"
sb.replace(0, 5, "Java");   // replace range
sb.toString();              // convert back to String
sb.length();                // current length
sb.charAt(0);
sb.setCharAt(0, 'j');
```

**Performance comparison:**

```java
// BAD: creates thousands of String objects
String result = "";
for (int i = 0; i < 10000; i++) {
    result += i;  // O(n²) time complexity
}

// GOOD: uses a single mutable buffer
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i); // O(n) time complexity
}
String result2 = sb.toString();
```

## Java 11+ String Methods

```java
" ".isBlank()                  // true (only whitespace)
"  hi  ".strip()               // "hi" (Unicode-aware trim)
"line1\nline2\nline3".lines()  // Stream<String> of each line
"ab".repeat(3)                 // "ababab"
```

## Interning

```java
String s = new String("hello").intern(); // forces into pool
// s now points to the pool entry
```

Use `intern()` cautiously. Overuse can bloat the pool.
