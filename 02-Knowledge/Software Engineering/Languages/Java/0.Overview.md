# Java

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. It follows the **Write Once, Run Anywhere (WORA)** principle — compiled to bytecode that runs on any JVM.

## Version History

| Version | Key Features | LTS |
|---------|-------------|-----|
| Java 8 | Lambdas, Streams, Optional, Date/Time API | Yes |
| Java 9 | Modules, `List.of()`, Stream improvements | |
| Java 10 | `var` type inference | |
| Java 11 | New String methods, `HttpClient` | Yes |
| Java 14 | Records (preview), Switch expressions | |
| Java 16 | Records (stable), `instanceof` pattern matching | |
| Java 17 | Sealed classes, Pattern matching for switch | Yes |
| Java 21 | Virtual threads, Pattern matching, Sequenced collections | Yes |
