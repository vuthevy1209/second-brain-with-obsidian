## Platform Independence

Java follows the **"Write Once, Run Anywhere"** (WORA) principle. Source code is compiled into **bytecode** (`.class` files) by the Java Compiler (`javac`), and then interpreted/JIT-compiled by the **Java Virtual Machine (JVM)** on any supported platform.

```
Source Code (.java) → Compiler (javac) → Bytecode (.class) → JVM → Native Machine Code
```

## JVM, JRE, JDK

| Component | Description |
|-----------|-------------|
| **JVM** (Java Virtual Machine) | Executes bytecode. Platform-specific. Includes JIT compiler. |
| **JRE** (Java Runtime Environment) | JVM + standard libraries. Needed to *run* Java programs. |
| **JDK** (Java Development Kit) | JRE + compiler (`javac`) + tools. Needed to *develop* Java programs. |

## Object-Oriented Programming Pillars

Java is fundamentally object-oriented. All code lives inside classes.

**Encapsulation** — Bundling data and behavior together; hiding internal state via access modifiers (`private`, `protected`, `public`).

**Inheritance** — A class (subclass) can extend another class (superclass) using `extends`, inheriting fields and methods. Java supports single inheritance for classes.

**Polymorphism** — The same interface can be used for different underlying types:
- *Compile-time (static)*: Method overloading — same method name, different parameters.
- *Runtime (dynamic)*: Method overriding — subclass provides its own implementation of a superclass method.

**Abstraction** — Hiding implementation details. Achieved via `abstract` classes and `interfaces`.

## Classes and Objects

A **class** is a blueprint. An **object** is an instance of a class.

```java
public class Car {
    // Fields (state)
    private String model;
    private int year;

    // Constructor
    public Car(String model, int year) {
        this.model = model;
        this.year = year;
    }

    // Method (behavior)
    public String getModel() {
        return model;
    }
}

// Creating an object
Car myCar = new Car("Tesla", 2024);
```

## Static vs Instance Members

**Static members** belong to the class, not to any instance. Shared across all objects.

```java
public class Counter {
    private static int count = 0; // shared across all instances
    private int id;

    public Counter() {
        count++;
        this.id = count; // instance field
    }

    public static int getCount() { return count; } // static method
    public int getId() { return id; }             // instance method
}
```

## The `final` Keyword

- `final` **variable** → constant; cannot be reassigned
- `final` **method** → cannot be overridden in subclasses
- `final` **class** → cannot be subclassed (e.g., `String`, `Integer`)

## Abstract Classes vs Interfaces

| Feature | Abstract Class | Interface |
|---------|---------------|-----------|
| Instantiation | Cannot be instantiated | Cannot be instantiated |
| Methods | Can have concrete + abstract methods | Default & static concrete methods (Java 8+) |
| Fields | Can have instance fields | Only `public static final` constants |
| Inheritance | `extends` (single) | `implements` (multiple) |
| Constructor | Can have constructors | No constructors |
| Use case | Shared base with partial implementation | Define a contract/capability |

```java
// Abstract class
abstract class Shape {
    abstract double area();

    public void printArea() {
        System.out.println("Area: " + area());
    }
}

// Interface
interface Drawable {
    void draw(); // implicitly public abstract

    default void highlight() {
        System.out.println("Highlighting shape");
    }
}

class Circle extends Shape implements Drawable {
    double radius;
    Circle(double r) { this.radius = r; }

    @Override
    public double area() { return Math.PI * radius * radius; }

    @Override
    public void draw() { System.out.println("Drawing circle"); }
}
```

## Memory Model

**Stack** — Stores local variables, method call frames. LIFO. Thread-safe per thread. Fast allocation/deallocation.

**Heap** — Stores all objects. Shared among threads. Managed by the Garbage Collector.

**Garbage Collection (GC)** — Automatically reclaims memory from objects no longer reachable. Key algorithms:
- **Serial GC** — Single-threaded, good for small applications
- **Parallel GC** — Multi-threaded GC, good for throughput
- **G1 GC** — Default since Java 9. Balances throughput and latency.
- **ZGC / Shenandoah** — Ultra-low pause time GCs (Java 11+)

## Packages and Imports

Packages provide namespace management and access control.

```java
package com.example.myapp;   // declares package

import java.util.List;        // single class import
import java.util.*;           // wildcard import (avoid in production)
import static java.lang.Math.PI; // static import
```

## The `this` and `super` Keywords

- `this` — refers to the current instance. Used to disambiguate fields from parameters.
- `super` — refers to the parent class. Used to call parent constructors or overridden methods.

```java
class Animal {
    String name;
    Animal(String name) { this.name = name; }
    void speak() { System.out.println("..."); }
}

class Dog extends Animal {
    String breed;
    Dog(String name, String breed) {
        super(name);         // calls Animal constructor
        this.breed = breed;  // `this` clarifies field vs param
    }

    @Override
    void speak() {
        super.speak();       // calls Animal.speak()
        System.out.println("Woof!");
    }
}
```
