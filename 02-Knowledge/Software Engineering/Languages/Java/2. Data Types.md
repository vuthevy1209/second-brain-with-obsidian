# Java Data Types

## Overview

Java is a **statically typed** language — every variable has a type declared at compile time. Types are divided into two categories:

- **Primitive types** — store raw values directly on the stack
- **Reference types** — store a reference (address) to an object on the heap

## Primitive Types

Java has 8 primitive types:

| Type | Size | Range | Default | Wrapper |
|------|------|-------|---------|---------|
| `byte` | 8-bit | -128 to 127 | 0 | `Byte` |
| `short` | 16-bit | -32,768 to 32,767 | 0 | `Short` |
| `int` | 32-bit | -2³¹ to 2³¹-1 | 0 | `Integer` |
| `long` | 64-bit | -2⁶³ to 2⁶³-1 | 0L | `Long` |
| `float` | 32-bit | ~±3.4×10³⁸ (7 digits) | 0.0f | `Float` |
| `double` | 64-bit | ~±1.7×10³⁰⁸ (15 digits) | 0.0d | `Double` |
| `boolean` | 1-bit* | `true` / `false` | `false` | `Boolean` |
| `char` | 16-bit | 0 to 65,535 (Unicode) | `'\u0000'` | `Character` |

*JVM implementation-dependent; often stored as 32-bit in arrays

```java
int age = 25;
long population = 8_000_000_000L;  // L suffix required
float price = 9.99f;               // f suffix required
double pi = 3.14159265358979;
boolean active = true;
char grade = 'A';
byte b = 127;
short s = 32000;
```

## Underscores in Numeric Literals (Java 7+)

Underscores improve readability for large numbers and have no effect on the value:

```java
int million = 1_000_000;
long creditCard = 1234_5678_9012_3456L;
double hex = 0xFF_EC_D1_8C;
```

## Reference Types

Everything that is not a primitive is a reference type. This includes:
- **Classes** (e.g., `String`, `Scanner`, custom classes)
- **Arrays**
- **Interfaces**
- **Enums**

Reference variables hold a memory address, not the actual object.

```java
String name = "Alice";  // name holds a reference to a String object
int[] nums = {1, 2, 3}; // nums holds a reference to an array object
```

## Type Conversion

### Widening (Implicit) Conversion

Automatic promotion from smaller to larger type. No data loss.

```
byte → short → int → long → float → double
                char → int
```

```java
int i = 100;
long l = i;    // widening: int → long (implicit)
double d = i;  // widening: int → double (implicit)
```

### Narrowing (Explicit) Conversion

Requires explicit cast. Potential data loss or precision loss.

```java
double d = 9.99;
int i = (int) d;    // i = 9, fractional part truncated

long l = 1234567890123L;
int i2 = (int) l;   // data loss possible
```

### String Conversion

```java
// Primitive → String
String s1 = String.valueOf(42);
String s2 = Integer.toString(42);
String s3 = "" + 42;  // concatenation trick (avoid in loops)

// String → Primitive
int n = Integer.parseInt("42");
double d = Double.parseDouble("3.14");
boolean b = Boolean.parseBoolean("true");
```

## Wrapper Classes

Each primitive has a corresponding **wrapper class** in `java.lang`. Wrappers allow primitives to be used where objects are required (e.g., in collections).

```java
Integer boxed = Integer.valueOf(42);  // explicit boxing
int unboxed = boxed.intValue();       // explicit unboxing

// Autoboxing (Java 5+) — compiler handles conversion automatically
Integer auto = 42;          // autoboxing
int back = auto;            // auto-unboxing
```

### Useful Wrapper Methods

```java
Integer.MAX_VALUE          // 2147483647
Integer.MIN_VALUE          // -2147483648
Integer.toBinaryString(10) // "1010"
Integer.toHexString(255)   // "ff"
Integer.parseInt("FF", 16) // 255 (parse hex string)
Integer.compare(5, 10)     // -1 (negative means 5 < 10)
Integer.sum(3, 4)          // 7
```

## Autoboxing Pitfalls

```java
// Integer cache: -128 to 127 are cached
Integer a = 127;
Integer b = 127;
System.out.println(a == b);   // true (same cached object)

Integer c = 128;
Integer d = 128;
System.out.println(c == d);   // false (different objects!)
System.out.println(c.equals(d)); // true (compare values)
```

Always use `.equals()` to compare wrapper objects, never `==`.

## Arrays

Arrays are reference types with fixed size. Zero-indexed.

```java
// Declaration and initialization
int[] arr1 = new int[5];         // default values (0)
int[] arr2 = {1, 2, 3, 4, 5};   // array literal
int[] arr3 = new int[]{1, 2, 3}; // explicit array literal

// Multidimensional
int[][] matrix = new int[3][4];
int[][] grid = {{1,2}, {3,4}, {5,6}};

// Array properties and operations
arr1.length;           // 5
Arrays.sort(arr2);     // sort in place
Arrays.copyOf(arr2, 3); // copy first 3 elements
Arrays.fill(arr1, 0);  // fill with value
System.arraycopy(src, srcPos, dest, destPos, length); // fast copy
```

## Varargs

A method can accept a variable number of arguments of the same type using `...`:

```java
public int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) total += n;
    return total;
}

sum(1, 2);         // works
sum(1, 2, 3, 4);   // works
sum(new int[]{1,2,3}); // also works
```

Varargs must be the last parameter. Only one varargs parameter per method.

## `var` — Local Variable Type Inference (Java 10+)

`var` lets the compiler infer the type of a local variable:

```java
var message = "Hello";       // inferred as String
var list = new ArrayList<>(); // inferred as ArrayList<Object>
var count = 0;                // inferred as int

// Only works for local variables (not fields or parameters)
for (var item : list) { ... } // works in for-each
```

## Enum

Enums are a special reference type for a fixed set of named constants:

```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY;

    public boolean isWeekend() {
        return this == SATURDAY || this == SUNDAY;
    }
}

Day today = Day.FRIDAY;
System.out.println(today.isWeekend()); // false
System.out.println(today.name());      // "FRIDAY"
System.out.println(today.ordinal());   // 4
```
