# Java Generics

## What are Generics?

Generics enable **type-safe** code by allowing classes, interfaces, and methods to operate on any type while specifying the exact type at use time. They eliminate explicit casting and catch type errors at compile time.

```java
// Without generics (pre-Java 5)
List list = new ArrayList();
list.add("hello");
String s = (String) list.get(0); // explicit cast, ClassCastException risk

// With generics
List<String> list = new ArrayList<>();
list.add("hello");
String s = list.get(0);  // no cast needed, type-safe
```

## Generic Classes

```java
public class Box<T> {
    private T value;

    public Box(T value) {
        this.value = value;
    }

    public T get() {
        return value;
    }

    public void set(T value) {
        this.value = value;
    }
}

// Usage
Box<String> strBox = new Box<>("Hello");
Box<Integer> intBox = new Box<>(42);
String s = strBox.get();  // type-safe, no cast
```

## Multiple Type Parameters

```java
public class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey() { return key; }
    public V getValue() { return value; }
}

Pair<String, Integer> p = new Pair<>("Alice", 30);
```

## Generic Methods

```java
public class Utils {
    // Generic method — T is scoped to this method
    public static <T> T identity(T item) {
        return item;
    }

    public static <T extends Comparable<T>> T max(T a, T b) {
        return a.compareTo(b) >= 0 ? a : b;
    }

    public static <T> void swap(T[] arr, int i, int j) {
        T temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}

String s = Utils.identity("hello");
int m = Utils.max(3, 7); // 7
```

## Bounded Type Parameters

### Upper Bound (`extends`)

Restricts the type to a specific class or its subclasses:

```java
// T must be Number or a subclass (Integer, Double, etc.)
public <T extends Number> double sum(List<T> list) {
    double total = 0;
    for (T n : list) {
        total += n.doubleValue();
    }
    return total;
}

sum(List.of(1, 2, 3));      // works — Integer extends Number
sum(List.of(1.5, 2.5));     // works — Double extends Number
// sum(List.of("a", "b")); // compile error — String does not extend Number
```

### Multiple Bounds

```java
public <T extends Comparable<T> & Serializable> T process(T item) {
    // T must implement both Comparable and Serializable
    return item;
}
```

## Wildcards

### Unbounded Wildcard `?`

Accepts any type. Use when the type doesn't matter:

```java
public void printList(List<?> list) {
    for (Object o : list) {
        System.out.println(o);
    }
}
printList(List.of(1, 2, 3));
printList(List.of("a", "b"));
```

### Upper Bounded Wildcard `? extends T`

Accepts `T` or any subtype. **Read-only** (producer).

```java
public double sumList(List<? extends Number> list) {
    double sum = 0;
    for (Number n : list) sum += n.doubleValue();
    return sum;
}
// list.add(1); // compile error — cannot add to ? extends
```

### Lower Bounded Wildcard `? super T`

Accepts `T` or any supertype. **Write-only** (consumer).

```java
public void addNumbers(List<? super Integer> list) {
    list.add(1);
    list.add(2);
    // Object o = list.get(0); // only Object is safe to read
}
```

### PECS Principle

**Producer Extends, Consumer Super**

```java
// Source (producer) — use extends
public void copy(List<? extends T> src, List<? super T> dest) {
    for (T item : src) {   // read from producer
        dest.add(item);    // write to consumer
    }
}
```

## Type Erasure

Java generics use **type erasure** — generic type information is removed at compile time. At runtime, all generic types become their raw form (or their bound).

```java
List<String> strList = new ArrayList<>();
List<Integer> intList = new ArrayList<>();

// At runtime, both are just List (raw type)
System.out.println(strList.getClass() == intList.getClass()); // true

// This check always succeeds (cannot check generic type at runtime)
if (strList instanceof List) { ... } // OK
// if (strList instanceof List<String>) { ... } // compile error
```

**Implications:**
- Cannot create `new T()` directly
- Cannot create arrays of generic types: `new T[10]` is illegal
- `instanceof` cannot check generic type parameters

```java
// Workaround for creating instances — use Class<T>
public class Factory<T> {
    private Class<T> type;

    public Factory(Class<T> type) {
        this.type = type;
    }

    public T create() throws Exception {
        return type.getDeclaredConstructor().newInstance();
    }
}
```

## Common Generic Collections Usage

```java
// Diamond operator — compiler infers type
List<Map<String, List<Integer>>> complex = new ArrayList<>();

// Generic method inference
List<String> list = Collections.emptyList();     // inferred as List<String>
Optional<String> opt = Optional.empty();         // inferred as Optional<String>
```

## Restrictions on Generics

```java
// Cannot use primitives as type arguments
List<int> bad = new ArrayList<>();     // compile error
List<Integer> ok = new ArrayList<>();  // use wrapper class

// Cannot instantiate type parameter
T item = new T();   // compile error

// Cannot create generic arrays
T[] arr = new T[10]; // compile error (use List<T> instead)

// Cannot use instanceof with parameterized types
if (obj instanceof List<String>) { }  // compile error

// Static members cannot use class type parameter
class Box<T> {
    static T value; // compile error — T not in scope for static
}
```
