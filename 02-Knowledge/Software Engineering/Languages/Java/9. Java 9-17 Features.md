# Java 9–17 Features

## Java 9

### Module System (Project Jigsaw)

Introduced the **Java Platform Module System (JPMS)** — a way to encapsulate packages beyond the level that packages alone can provide.

```
// module-info.java (in src/main/java/)
module com.example.myapp {
    requires java.base;          // implicit, but explicit is fine
    requires java.sql;
    requires com.example.utils;

    exports com.example.api;     // make this package visible to others
    opens com.example.model;     // allow reflective access (for frameworks)
}
```

### `List.of()`, `Set.of()`, `Map.of()`

Factory methods for immutable collections (see [[4. Collections Framework]]):

```java
List<String> list = List.of("a", "b", "c");
Set<Integer> set = Set.of(1, 2, 3);
Map<String, Integer> map = Map.of("a", 1, "b", 2);
```

### `Optional` Improvements

```java
Optional<String> opt = Optional.empty();
opt.ifPresentOrElse(
    s -> System.out.println("Found: " + s),
    () -> System.out.println("Not found")
);
opt.stream();        // returns Stream<T> of 0 or 1 elements
opt.or(() -> Optional.of("default")); // if empty, use another Optional
```

### Stream Improvements

```java
// takeWhile — take elements while predicate is true
Stream.of(1, 2, 3, 4, 5, 1, 2)
    .takeWhile(n -> n < 4)   // [1, 2, 3]

// dropWhile — drop elements while predicate is true
Stream.of(1, 2, 3, 4, 5, 1, 2)
    .dropWhile(n -> n < 4)   // [4, 5, 1, 2]

// iterate with predicate (finite stream)
Stream.iterate(1, n -> n < 100, n -> n * 2)   // [1, 2, 4, 8, 16, 32, 64]

// ofNullable
Stream.ofNullable(null)  // empty stream (avoids NPE)
Stream.ofNullable("hi")  // Stream of "hi"
```

### Private Interface Methods

```java
interface MyInterface {
    default void publicMethod() {
        helper(); // use private helper
    }

    private void helper() {  // Java 9+
        System.out.println("internal logic");
    }
}
```

## Java 10

### `var` — Local Variable Type Inference

```java
var message = "Hello, World!";     // String
var list = new ArrayList<String>(); // ArrayList<String>
var map = new HashMap<String, Integer>(); // HashMap<String, Integer>

// Works in for-each loops
for (var entry : map.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

// Restrictions:
// - Only local variables (not fields, parameters, return types)
// - Must be initialized at declaration
// - Cannot be null without explicit type
```

### `Collectors.toUnmodifiableList/Set/Map()`

```java
List<String> immutable = stream.collect(Collectors.toUnmodifiableList());
```

## Java 11

### New String Methods

```java
"  ".isBlank()              // true (whitespace only)
"  hello  ".strip()         // "hello" (Unicode-aware trim)
"  hello  ".stripLeading()  // "hello  "
"  hello  ".stripTrailing() // "  hello"
"ab".repeat(3)              // "ababab"
"a\nb\nc".lines()           // Stream<String>: ["a", "b", "c"]
```

### `var` in Lambda Parameters

```java
List<String> list = List.of("a", "b", "c");
list.stream()
    .map((@NotNull var s) -> s.toUpperCase()) // var with annotation
    .forEach(System.out::println);
```

### `Files` Improvements

```java
Path path = Path.of("file.txt");
String content = Files.readString(path);
Files.writeString(path, "hello");
```

### `HttpClient` (Standard)

The new `HttpClient` API (incubated in Java 9, standardized in Java 11):

```java
HttpClient client = HttpClient.newHttpClient();

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/data"))
    .header("Accept", "application/json")
    .GET()
    .build();

HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.statusCode()); // 200
System.out.println(response.body());

// Async
client.sendAsync(request, HttpResponse.BodyHandlers.ofString())
    .thenApply(HttpResponse::body)
    .thenAccept(System.out::println);
```

## Java 12–13

### Switch Expressions (Preview → Standard in Java 14)

The new switch syntax as an **expression** (returns a value) with arrow syntax:

```java
// Old switch statement
String result;
switch (day) {
    case MONDAY:
    case TUESDAY:
        result = "Weekday";
        break;
    default:
        result = "Weekend";
}

// New switch expression (Java 14+)
String result = switch (day) {
    case MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY -> "Weekday";
    case SATURDAY, SUNDAY -> "Weekend";
};

// With yield for block bodies
int numLetters = switch (day) {
    case MONDAY, FRIDAY, SUNDAY -> 6;
    case TUESDAY -> 7;
    default -> {
        String name = day.toString();
        yield name.length();  // yield returns value from block
    }
};
```

## Java 14

### Records (Preview → Standard Java 16)

Records are **immutable data classes** — automatically generate `equals()`, `hashCode()`, `toString()`, and accessors:

```java
record Point(int x, int y) {}

Point p = new Point(3, 4);
p.x();       // 3
p.y();       // 4
p.toString();  // "Point[x=3, y=4]"
p.equals(new Point(3, 4)); // true

// Records can have custom constructors and methods
record Range(int min, int max) {
    // Compact canonical constructor (validates)
    Range {
        if (min > max) throw new IllegalArgumentException("min must be ≤ max");
    }

    public int size() {
        return max - min;
    }
}
```

### `NullPointerException` Improvements

JVM now provides helpful NPE messages:

```
Cannot invoke "String.length()" because "name" is null
```

Instead of the old cryptic: `NullPointerException at line 42`

## Java 15

### Sealed Classes (Preview → Standard Java 17)

**Sealed classes** restrict which classes can extend or implement them:

```java
// Sealed class — only permitted subclasses can extend
public sealed class Shape permits Circle, Rectangle, Triangle {}

public final class Circle extends Shape {
    private final double radius;
    Circle(double r) { this.radius = r; }
    double area() { return Math.PI * radius * radius; }
}

public final class Rectangle extends Shape {
    private final double w, h;
    Rectangle(double w, double h) { this.w = w; this.h = h; }
    double area() { return w * h; }
}

// non-sealed allows further extension
public non-sealed class Triangle extends Shape { ... }
```

## Java 16

### `instanceof` Pattern Matching

Eliminates the explicit cast after `instanceof`:

```java
// Old way
if (obj instanceof String) {
    String s = (String) obj;  // explicit cast
    System.out.println(s.length());
}

// Pattern matching (Java 16+)
if (obj instanceof String s) {
    System.out.println(s.length()); // s is String, no cast needed
}

// Works in expressions
boolean isLong = obj instanceof String s && s.length() > 5;
```

## Java 17 (LTS)

### Pattern Matching for `switch` (Preview)

```java
// Combining sealed classes + pattern matching
static double area(Shape shape) {
    return switch (shape) {
        case Circle c -> Math.PI * c.radius() * c.radius();
        case Rectangle r -> r.width() * r.height();
        case Triangle t -> 0.5 * t.base() * t.height();
    };
}

// Guarded patterns with `when`
static String describe(Object obj) {
    return switch (obj) {
        case Integer i when i > 0 -> "Positive integer: " + i;
        case Integer i -> "Non-positive integer: " + i;
        case String s when s.isBlank() -> "Blank string";
        case String s -> "String: " + s;
        case null -> "null";
        default -> "Other: " + obj;
    };
}
```
