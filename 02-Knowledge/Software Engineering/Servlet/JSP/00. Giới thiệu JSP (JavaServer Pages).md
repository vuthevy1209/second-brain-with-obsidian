
### 1. JSP là gì? Bản chất của JSP

> [!NOTE] note
> - JSP (JavaServer Pages) ra đời với mục đích rất đơn giản: **Giúp viết HTML dễ hơn trong Java**.
> - Nếu dùng Servlet thuần, bạn phải dùng `out.print("<h1>Hello</h1>")` để in ra từng dòng HTML. Rất cực khổ và không thể thiết kế giao diện phức tạp được.

<mark style="background:#d3f8b6">JSP đảo ngược quá trình đó: Nó là một file HTML, nhưng cho phép bạn "nhúng" code Java vào giữa.</mark>

> [!IMPORTANT] Bản chất thực sự
> JSP **không có ma thuật**. Khi Tomcat lần đầu tiên chạy file `index.jsp`, nó sẽ dùng một công cụ ngầm dịch toàn bộ file `.jsp` đó thành một file `.java` (Servlet), rồi mới biên dịch ra `.class` để chạy. 
> 
> => <mark style="background:#d3f8b6">**Bản chất JSP chính là Servlet đang đội lốt HTML!**</mark>

### 2. Các cú pháp Java cổ điển trong JSP (Scriptlet)

Ngày xưa, các cụ lập trình viên hay viết code Java thẳng vào HTML bằng các cú pháp sau:

| Ký hiệu      | Tên gọi         | Tác dụng                                            | Chuyển sang Servlet ngầm                                          |
| :----------- | :-------------- | :-------------------------------------------------- | :---------------------------------------------------------------- |
| `<% ... %>`  | **Scriptlet**   | Chứa bất kỳ code Java logic nào (if, for, gọi hàm). | Được nhét vào trong lòng hàm `_jspService()`                      |
| `<%= ... %>` | **Expression**  | In giá trị một biến ra màn hình HTML.               | Được dịch thành `out.print(...)`                                  |
| `<%! ... %>` | **Declaration** | Khai báo biến toàn cục hoặc viết Hàm mới.           | Được ném ra ngoài class, biến thành thuộc tính của class Servlet. |

**Ví dụ kinh dị (Code thảm họa):**
```
<h1>Danh sách User:</h1>
<ul>
    <% 
        // 1. Viết Java khởi tạo dữ liệu và mở vòng lặp
        List<String> users = Arrays.asList("Vy", "Giám Đốc", "Sếp");
        
        for(String u : users) {
		    %>
    
            <!-- 2. Nhúng HTML vào giữa lòng vòng lặp Java -->
            <li> Xin chào: <%= u %> </li>
            
		    <% 
        // 3. Viết Java chỉ để... đóng cái ngoặc nhọn của hàm for!
        } 
    %>
</ul>
```

### 3. Sự tiến hóa: MVC, EL và JSTL

Vì viết Java bằng `<% %>` quá lộn xộn, cộng đồng Java Web đã đề ra luật thép: **Không bao giờ được viết code Java thuần vào file JSP nữa!** 

Từ đó Mô hình **MVC (Model - View - Controller)** ra đời:
1. **Controller (Servlet):** Chuyên làm não bộ, gọi Database, tính toán logic. Tính xong thì gói ghém data vào túi (`request.setAttribute`).
2. **View (JSP):** Chỉ có nhiệm vụ duy nhất là nhận túi Data đó và vẽ ra HTML.

Để vẽ được Data mà không cần `<% %>`, người ta sinh ra:
- **EL (Expression Language):** Dùng cú pháp `${...}` để lấy dữ liệu từ Request cực gọn.
- **JSTL (JSP Standard Tag Library):** Dùng các thẻ dạng HTML (`<c:forEach>`, `<c:if>`) để tạo vòng lặp và rẽ nhánh thay cho Java.

**Ví dụ Code hiện đại (Sạch sẽ):**

*Bên Servlet (Gửi dữ liệu):*
```java
request.setAttribute("userList", Arrays.asList("Vy", "Admin"));
request.getRequestDispatcher("user.jsp").forward(request, response);
```

*Bên JSP (Hiển thị bằng JSTL và EL):*
```jsp
<!-- Nhúng thư viện JSTL Core vào đầu file -->
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>

<h1>Danh sách User:</h1>
<ul>
    <!-- Vòng lặp siêu sạch sẽ, không có 1 miếng Java nào -->
    <c:forEach var="u" items="${userList}">
        <li> Xin chào: ${u} </li>
    </c:forEach>
</ul>
```
