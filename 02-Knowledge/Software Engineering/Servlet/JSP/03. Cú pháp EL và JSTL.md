# Cú pháp EL và JSTL (Modern JSP)

Để loại bỏ hoàn toàn mã Java thô (`<% %>`) ra khỏi HTML, lập trình viên sử dụng bộ đôi **EL** và **JSTL**.

---

### 1. EL (Expression Language)
EL giúp lấy dữ liệu siêu ngắn gọn bằng cú pháp `${...}` thay vì `request.getAttribute(...)`.

#### Cơ chế tự động tìm kiếm (Automatic Lookup)
Khi bạn gõ `${user}`, EL sẽ tự động lục lọi trong 4 cái Scope theo đúng thứ tự ưu tiên:
1. `pageScope` (Tìm nội bộ trang)
2. `requestScope` (Tìm trong Request)
3. `sessionScope` (Tìm trong Session)
4. `applicationScope` (Tìm trên toàn Server)
*Nếu tìm không thấy, nó in ra chuỗi rỗng chứ không thèm văng lỗi NullPointer!*

#### Các cú pháp kinh điển:
- **Lấy thuộc tính của Object**: `${user.name}` (Ngầm định gọi `user.getName()`)
- **Lấy phần tử Mảng/List**: `${users[0]}`
- **Toán tử 3 ngôi (Cực hay dùng)**: `${age >= 18 ? "Người lớn" : "Trẻ em"}`
- **Kiểm tra rỗng (Empty)**: `${empty listUser}` (Trả về `true` nếu List bằng null hoặc size = 0).
- **Lấy Form Input**: `${param.username}` (Thay cho `request.getParameter("username")`)

---

### 2. JSTL (JSP Standard Tag Library)
JSTL thay thế các vòng lặp `for` và lệnh `if/else` của Java bằng các thẻ giống hệt HTML.
Đầu tiên, phải import thư viện Core ở trên cùng file JSP:
```jsp
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
```

#### 🔁 1. Vòng lặp (`<c:forEach>`)
Dùng để duyệt qua Danh sách (List/Set/Array) gửi từ Servlet sang.
```jsp
<ul>
    <c:forEach var="item" items="${listProduct}">
        <li>Tên sản phẩm: ${item.name} - Giá: ${item.price}</li>
    </c:forEach>
</ul>
```

#### 🔀 2. Điều kiện (`<c:if>`)
Chú ý: JSTL chỉ có `<c:if>`, KHÔNG CÓ `<c:else>`.
```jsp
<c:if test="${empty listProduct}">
    <p>Hiện không có sản phẩm nào!</p>
</c:if>
```

#### 🔀 3. Switch-Case (`<c:choose>`)
Vì `<c:if>` không có `else`, nên nếu muốn kiểm tra nhiều nhánh (if-else-if), ta phải dùng bộ `<c:choose>`.
```jsp
<c:choose>
    <c:when test="${role == 'ADMIN'}">
        <button>Xóa người dùng</button>
    </c:when>
    <c:when test="${role == 'MODERATOR'}">
        <button>Khóa người dùng</button>
    </c:when>
    <c:otherwise>
        <!-- Tương đương thẻ else cuối cùng -->
        <p>Bạn chỉ được xem thôi.</p>
    </c:otherwise>
</c:choose>
```

#### 🔒 4. Thoát mã HTML chống XSS (`<c:out>`)
Khi in ra bất kỳ nội dung nào do người dùng tự nhập (Ví dụ: Bình luận), luôn luôn dùng `<c:out>`. Nó sẽ tự động mã hóa các thẻ `<script>` để chống Hacker tấn công XSS.
```jsp
<!-- TỐT: Nếu user nhập <script>alert(1)</script>, nó sẽ tự biến thành mã an toàn -->
<c:out value="${comment}" />

<!-- TỆ: Dễ bị dính chưởng XSS -->
${comment}
```
