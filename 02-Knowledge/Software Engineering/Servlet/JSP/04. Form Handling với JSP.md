# Form Handling với JSP và Servlet

Quy trình xử lý Form (Đăng ký, Đăng nhập) là tính năng xương sống của bất kỳ Web App nào.

### 1. Luồng xử lý Form (MVC Flow)
Sự kết hợp giữa Servlet (Controller) và JSP (View) để xử lý Form tuân theo mô hình sau:

1. **Khách hàng điền Form** trên trình duyệt (file `.jsp` hoặc `.html`).
2. Trình duyệt đóng gói dữ liệu và **Submit POST** lên Server.
3. **Servlet** đón Request, bóc tách dữ liệu bằng `request.getParameter()`.
4. Servlet tiến hành kiểm tra (Validate) dữ liệu, lưu vào Database.
5. Servlet nhét kết quả (Thông báo thành công/lỗi) vào lại Request (`request.setAttribute`).
6. Servlet **Forward (Chuyền tay)** Request đó sang một trang **JSP (Result)**.
7. JSP lấy kết quả ra bằng EL (`${...}`) và hiển thị HTML trả về cho người dùng.

---

### 2. Ví dụ: Chức năng Đăng Ký

#### Bước 1: View - Form nhập liệu (index.jsp)
```html
<form method="POST" action="/register">
    <label>Tên của bạn:</label>
    <input type="text" name="fullName" required />
    
    <!-- Hiển thị lỗi nếu Servlet trả về -->
    <p style="color: red;">${error}</p>
    
    <button type="submit">Đăng ký</button>
</form>
```

#### Bước 2: Controller - Servlet Xử lý (/register)
```java
@WebServlet("/register")
public class RegisterServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response) 
            throws ServletException, IOException {
        
        // 1. Lấy dữ liệu người dùng nhập
        String name = request.getParameter("fullName");
        
        // 2. Validate dữ liệu
        if (name == null || name.trim().length() < 3) {
            request.setAttribute("error", "Tên phải dài hơn 3 ký tự!");
            // Lỗi -> Forward về lại Form (kèm theo dòng thông báo lỗi)
            request.getRequestDispatcher("index.jsp").forward(request, response);
            return;
        }
        
        // 3. Xử lý Logic (Lưu DB, gửi Email,...)
        // ... Code ...
        
        // 4. Nhét dữ liệu thành công để báo cáo
        request.setAttribute("registeredName", name);
        request.setAttribute("success", true);
        
        // 5. Forward sang trang Kết quả
        request.getRequestDispatcher("result.jsp").forward(request, response);
    }
}
```

#### Bước 3: View - Trang kết quả (result.jsp)
```jsp
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>

<c:choose>
    <c:when test="${success}">
        <h1 style="color: green">Đăng ký thành công!</h1>
        <p>Chào mừng thành viên mới: <b>${registeredName}</b></p>
    </c:when>
    <c:otherwise>
        <h1 style="color: red">Hệ thống đang bảo trì, vui lòng thử lại!</h1>
    </c:otherwise>
</c:choose>
```

---

> [!WARNING] Cạm bẫy cực kỳ phổ biến
> Nếu người dùng **F5 (Refresh)** trang `result.jsp` sau khi đăng ký thành công, trình duyệt sẽ lặp lại hành động POST (Tức là đăng ký thêm 1 user y hệt như vậy nữa). Trình duyệt luôn hiện cái Popup cảnh báo: *"Confirm Form Resubmission"*.
> 
> **Cách khắc phục:** Dùng Pattern **PRG (Post-Redirect-Get)**. Thay vì dùng `forward` ở bước cuối cùng của khối thành công, hãy dùng `response.sendRedirect()`. (Chúng ta sẽ tìm hiểu sâu hơn ở bài Forward vs Redirect).
