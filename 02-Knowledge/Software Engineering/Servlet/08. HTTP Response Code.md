# Các mã HTTP Status Code kinh điển (Hay dùng nhất)

Khi code Servlet hay Spring Boot, đây là những mã trạng thái bạn sẽ dùng đi dùng lại mỗi ngày để báo cáo kết quả cho Trình duyệt/Client.

### 💡 Cách sử dụng trong Servlet:
```java
// Cách 1: Chỉ set mã (Dùng cho REST API trả về JSON)
resp.setStatus(HttpServletResponse.SC_BAD_REQUEST); // 400

// Cách 2: Quăng lỗi kèm thông báo (Tomcat sẽ văng ra trang HTML đỏ chót)
resp.sendError(HttpServletResponse.SC_UNAUTHORIZED, "Vui lòng đăng nhập!"); // 401
```

---

### 🟢 Nhóm 2xx: Thành công (Success)
- **200 OK**: Request thành công (Mặc định). Thường dùng khi `GET` hoặc `PUT`.
- **201 Created**: Tạo mới tài nguyên thành công (Insert DB). Rất hay dùng cho `POST`.
- **204 No Content**: Hành động thành công nhưng không cần trả về gì (Thường dùng cho `DELETE`).

### 🔵 Nhóm 3xx: Chuyển hướng (Redirection)
- **301 Moved Permanently**: URL cũ đã chết, chuyển sang URL mới vĩnh viễn (Rất quan trọng cho SEO Google).
- **302 Found**: Chuyển hướng tạm thời. Đây chính là mã được sinh ra khi bạn gọi hàm `resp.sendRedirect()`.

### 🟠 Nhóm 4xx: Lỗi do Client (Người dùng sai)
- **400 Bad Request**: Gửi thiếu tham số (`?id=...`), sai định dạng JSON, hoặc bắt nhập số mà gửi chữ.
- **401 Unauthorized**: Cửa đóng. Bạn CHƯA đăng nhập hoặc Token hết hạn.
- **403 Forbidden**: Bạn ĐÃ đăng nhập, nhưng bạn bị cấm cửa (Tài khoản User cố tình mò vào URL của Admin).
- **404 Not Found**: Khách hàng gõ sai đường dẫn URL, hoặc không tìm thấy dữ liệu trong Database.
- **405 Method Not Allowed**: Gọi sai phương thức. (Ví dụ: Servlet chỉ có `doPost()` nhưng lại dại dột gõ URL lên trình duyệt bằng `GET`).

### 🔴 Nhóm 5xx: Lỗi do Server (Dev sai)
- **500 Internal Server Error**: Báo động đỏ! Code Java bị văng Exception (Ví dụ: `NullPointerException`, chia cho 0, đứt cáp Database).
- **502 Bad Gateway / 504 Gateway Timeout**: Lỗi mạng (Thường gặp khi Nginx hoặc Load Balancer không kết nối được tới Tomcat).
