# 4 Vùng Nhớ (Scope) Kinh Điển Trong Servlet/JSP


> [!NOTE] Note
> Trong lập trình Web Java, để truyền dữ liệu (Data) từ nơi này sang nơi khác (ví dụ từ Servlet ném sang JSP), chúng ta dùng cơ chế `setAttribute("key", data)` và `getAttribute("key")`. 

<mark style="background:#affad1">=> Nhưng câu hỏi quan trọng nhất là: **"Dữ liệu này sẽ sống được bao lâu?"**</mark>

Có 4 cấp độ sống sót của dữ liệu, xếp theo thứ tự vòng đời từ ngắn nhất đến dài nhất:

### 1. Page Scope (Chỉ JSP mới có)

- **Vòng đời:** Sống siêu ngắn. Dữ liệu chỉ tồn tại duy nhất trên **chính trang JSP đang render**. Ngay cả khi bạn tách nhỏ layout và dùng thẻ `<jsp:include>` để nhúng một trang khác (vd: `header.jsp`) vào trang hiện tại (`index.jsp`), thì `header.jsp` **KHÔNG THỂ** nhìn thấy các biến lưu bằng Page Scope của `index.jsp`.
- **Cách gọi:** `pageContext.setAttribute("key", value);` hoặc thông qua JSTL `<c:set var="key" value="value" scope="page" />`
- **Ví dụ minh họa tính cục bộ:**
  Giả sử trong file `index.jsp` bạn khai báo:
  ```jsp
  <%
      // Khai báo biến vào Page Scope
      pageContext.setAttribute("pageTitle", "Trang Chủ");
      
      // Khai báo biến vào Request Scope
      request.setAttribute("username", "Vy");
  %>
  
  <!-- In biến ra ngay tại file index.jsp (Cả 2 đều hiển thị) -->
  <h1>${pageTitle} - Xin chào ${username}</h1>
  
  <!-- Nhúng file header.jsp vào -->
  <jsp:include page="header.jsp" />
  ```
  Nhưng khi chạy sang file `header.jsp`:
  ```jsp
  <!-- LỖI TÀNG HÌNH: ${pageTitle} sẽ bị RỖNG vì nó không vượt qua được biên giới file index.jsp -->
  <h2>Tiêu đề là: ${pageTitle}</h2> 
  
  <!-- THÀNH CÔNG: ${username} vẫn hiển thị vì Request Scope chia sẻ cho mọi file cùng tham gia xử lý Request này -->
  <p>Người dùng: ${username}</p>
  ```
- **Ứng dụng:** Cực kỳ hiếm dùng để truyền dữ liệu. Chỉ thỉnh thoảng dùng để lưu các biến tạm thời siêu nhỏ (như index vòng lặp `i`, chuỗi định dạng tiền tệ tạm) ngay trong lòng 1 trang JSP để tránh đặt tên trùng lặp với các file khác.

### 2. Request Scope (Dùng nhiều nhất)

- **Vòng đời:** Sống trọn vẹn trong **một lần Client gửi Request lên Server**. 
- <mark style="background:#d3f8b6">Dù nội bộ Server có `forward` (chuyền tay) cái Request đó qua 5 cái Servlet và 3 cái JSP đi chăng nữa, thì dữ liệu vẫn còn nguyên. Nhưng ngay khi Server trả kết quả (Response) về cho trình duyệt, vùng nhớ này sẽ bị dọn dẹp.</mark>
- *(Lưu ý: Nếu dùng `sendRedirect` sinh ra Request số 2 thì dữ liệu của Request 1 sẽ mất).*
- **Cách gọi:** `request.setAttribute("key", value);`
- **Ứng dụng:** Trả về danh sách sản phẩm từ Database để JSP vẽ thành Bảng, Thông báo lỗi nhập sai Form.

### 3. Session Scope (Lưu dấu vết Cá nhân)

- **Vòng đời:** Gắn liền với **Trình duyệt của từng người**. Khi user vào web, Server phát cho 1 túi Session riêng (đánh dấu bằng `JSESSIONID` trên Cookie). Khách có nhảy sang trang khác, bấm F5, gửi bao nhiêu Request đi nữa thì túi này vẫn giữ nguyên. Nó chỉ chết khi: Quá hạn Timeout (thường là 30 phút không hoạt động), hoặc gọi hàm Invalid (Đăng xuất).
- **Cách gọi:** 
  ```java
  HttpSession session = request.getSession();
  session.setAttribute("user", userObj);
  ```
- **Ứng dụng kinh điển:** Lưu thông tin User đang đăng nhập, Giỏ hàng mua sắm (Shopping Cart), Ngôn ngữ/Theme (Dark/Light) người đó đang chọn.

### 4. Application Scope (Chia sẻ Toàn cầu)

- **Vòng đời:** Sống siêu dai. Khởi sinh khi **Tomcat bật lên** và chỉ chết khi **Tomcat bị tắt đi**. Dữ liệu ở đây là của chung. TẤT CẢ mọi người dùng trên mọi Session đều nhìn thấy và thao tác trên cùng một vùng nhớ này.
- **Cách gọi:** 
  ```java
  ServletContext context = getServletContext(); 
  context.setAttribute("totalVisitors", count);
  ```
- **Ứng dụng kinh điển:** Đếm tổng số lượt truy cập toàn website, Số người đang Online, Cấu hình hệ thống dùng chung (vd: Tiêu đề Website).

---

> [!IMPORTANT] Mẹo chốt hạ khi đi Phỏng vấn
> Tưởng tượng bạn bước vào nhà hàng ăn:
> - **Page Scope**: Những dòng bạn viết nháp trên mặt tờ giấy gọi món (Lật sang tờ khác là mất).
> - **Request Scope**: Lời bạn gọi món với bồi bàn (Bồi bàn nghe xong, báo bếp nấu, bưng đồ ăn ra là kết thúc nhiệm vụ).
> - **Session Scope**: Cái bàn bạn đang ngồi (Bạn ngồi 2 tiếng đồng hồ, gọi thêm 10 lần món nữa, thì cái bàn đó vẫn là của riêng bạn, khách khác không được ngồi chung).
> - **Application Scope**: Cái Tivi treo tường của nhà hàng (Mọi cái bàn, mọi khách hàng trong phòng đều nhìn chung 1 màn hình Tivi).
