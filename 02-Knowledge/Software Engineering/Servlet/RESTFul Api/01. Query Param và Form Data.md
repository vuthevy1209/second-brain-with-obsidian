# 1. Trích xuất Query Param & Form Data (GET / POST)

Trong Spring Boot, chúng ta nhàn rỗi nhờ có `@RequestParam`. Nhưng trong Servlet thuần, mọi thứ đều phải móc qua `req.getParameter()` và xử lý ép kiểu bằng tay.

### So sánh Code

**1. Phía Spring Boot:**
```java
@GetMapping("/search")
public String search(
        @RequestParam("keyword") String keyword,
        @RequestParam(value = "page", defaultValue = "1") int page,
        @RequestParam("color") List<String> colors) {
    // Spring tự parse String, int và List
    return "search-result";
}
```

**2. Phía Servlet Thuần:**
```java
@WebServlet("/api/search")
public class QueryParamApiServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        req.setCharacterEncoding("UTF-8");
        resp.setContentType("application/json;charset=UTF-8");

        // Lấy String đơn
        String keyword = req.getParameter("keyword");

        // Tự ép kiểu số & xử lý giá trị mặc định
        String pageStr = req.getParameter("page");
        int page = (pageStr != null && !pageStr.isBlank()) ? Integer.parseInt(pageStr) : 1;

        // Lấy danh sách (Mảng) nhiều giá trị
        String[] colors = req.getParameterValues("color");
        int colorsCount = (colors != null) ? colors.length : 0;
        
        resp.getWriter().printf("{\"keyword\": \"%s\", \"page\": %d, \"colors_selected_count\": %d}", keyword, page, colorsCount);
    }
}
```
