# 4. Trích xuất Request Header & Cookie

Header và Cookie thường được dùng để gửi Token xác thực (JWT) hoặc lưu trạng thái ẩn. Spring có `@RequestHeader` và `@CookieValue`. Servlet có hàm `getHeader()` cực kỳ dễ dùng, nhưng `getCookies()` thì hơi vất vả vì trả về mảng.

### So sánh Code

**1. Phía Spring Boot:**
```java
@GetMapping("/profile")
public String getProfile(
        @RequestHeader("Authorization") String bearerToken,
        @CookieValue(name = "userTheme", defaultValue = "light") String theme) {
    return "profile-view";
}
```

**2. Phía Servlet Thuần:**
```java
@WebServlet("/api/profile")
public class HeaderCookieApiServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        resp.setContentType("application/json;charset=UTF-8");
        
        // 1. Lấy Header
        String authHeader = req.getHeader("Authorization");
        String userAgent = req.getHeader("User-Agent");
        
        // 2. Lấy Cookie
        String theme = "light (mặc định)";
        Cookie[] cookies = req.getCookies(); // Rất phiền vì trả về Array
        if (cookies != null) {
            for (Cookie c : cookies) {
                if ("userTheme".equals(c.getName())) {
                    theme = c.getValue();
                    break;
                }
            }
        }
        
        resp.getWriter().printf("{\"authorization_token\": \"%s\", \"user_theme\": \"%s\", \"user_agent\": \"%s\"}", authHeader, theme, userAgent);
    }
}
```
