# 5. Upload File (`multipart/form-data`)

Upload File là bài toán phức tạp nhất. Servlet 3.0 trở lên cung cấp API `@MultipartConfig` và `Part` để bắt file.

### So sánh Code

**1. Phía Spring Boot:**
```java
@PostMapping("/upload")
public String uploadFile(@RequestPart("avatar") MultipartFile file) {
    // Spring MultipartFile cung cấp cực kỳ nhiều hàm tiện ích
    return "success";
}
```

**2. Phía Servlet Thuần:**
```java
@WebServlet("/api/upload")
@MultipartConfig(fileSizeThreshold = 1024 * 1024 * 2, maxFileSize = 1024 * 1024 * 10)
public class UploadApiServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        resp.setContentType("application/json;charset=UTF-8");
        
        Part filePart = req.getPart("avatar");
        if (filePart != null) {
            String fileName = filePart.getSubmittedFileName();
            long size = filePart.getSize();
            resp.getWriter().printf("{\"status\": \"Thành công\", \"fileName\": \"%s\", \"sizeBytes\": %d}", fileName, size);
        } else {
            resp.getWriter().printf("{\"status\": \"Thất bại\", \"message\": \"Không tìm thấy file có tên 'avatar'\"}");
        }
    }
}
```

### 🚀 Test với Postman (cURL)
Vì cURL gửi file phức tạp, bạn hãy dùng Postman như sau:
1. Tạo Request **POST** `http://localhost:8080/learn_servlet_war_exploded/api/upload`
2. Sang tab **Body**, chọn **form-data**.
3. Tại ô **KEY**, gõ chữ `avatar`. Bấm vào dropdown nhỏ kế bên chữ `avatar` đổi từ "Text" sang **"File"**.
4. Tại ô **VALUE**, bấm *Select Files* và chọn một file bất kỳ (ảnh nhỏ).
5. Bấm **SEND** và xem kết quả JSON trả về kích thước file!
