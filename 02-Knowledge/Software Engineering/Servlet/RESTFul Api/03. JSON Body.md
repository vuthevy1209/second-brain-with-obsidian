# 3. Trích xuất chuỗi JSON Raw (Request Body)

Khi code REST API, Client gửi data lên bằng chuỗi JSON (Raw Body). Spring Boot có `@RequestBody` tự động nhờ thư viện Jackson/Gson tích hợp sẵn. Với Servlet, bạn phải tự mở InputStream và tự gọi thư viện (như Google Gson) để convert.

### So sánh Code

**1. Phía Spring Boot:**
```java
@PostMapping("/api/login")
public ResponseEntity<AuthResponse> login(@RequestBody LoginRequest loginDto) {
    // Jackson tự động chuyển JSON trong body sang object LoginRequest
    return ResponseEntity.ok(authService.login(loginDto));
}
```

**2. Phía Servlet Thuần:**
```java
@WebServlet("/api/login")
public class JsonBodyApiServlet extends HttpServlet {
    private final Gson gson = new Gson();

    static class LoginDto {
        String username;
        String password;
    }

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        req.setCharacterEncoding("UTF-8");
        resp.setContentType("application/json;charset=UTF-8");

        // 1. Đọc từng dòng chuỗi JSON từ InputStream của Request
        StringBuilder sb = new StringBuilder();
        try (BufferedReader reader = req.getReader()) {
            String line;
            while ((line = reader.readLine()) != null) {
                sb.append(line);
            }
        }
        
        // 2. Dùng thư viện Gson để Parse chuỗi JSON sang Object (Deserialize)
        LoginDto dto = gson.fromJson(sb.toString(), LoginDto.class);
        
        /* 
         * CÁCH 1 (Thủ công - Dễ sai cú pháp):
         * resp.getWriter().printf("{\"message\": \"Đăng nhập thành công\", \"username\": \"%s\"}", dto.username);
         */

        // CÁCH 2 (Chuyên nghiệp - Serialize bằng Gson):
        Map<String, Object> responseData = new HashMap<>();
        responseData.put("message", "Đăng nhập thành công");
        responseData.put("username_received", dto != null ? dto.username : null);
        
        // Bảo Gson tự build ra JSON và ghi thẳng vào luồng Response Writer!
        gson.toJson(responseData, resp.getWriter());
    }
}
```
