# 2. Trích xuất Path Variable (URL RESTful)

Trích xuất tham số động trên URL là sức mạnh tuyệt đối của Spring Boot `@PathVariable`. Tuy nhiên, Servlet API ra đời trước khái niệm RESTful, nên nó không hỗ trợ bóc tách trực tiếp. Bạn phải cấu hình Servlet mapping wildcard `/*` và tự bóc chuỗi bằng tay.

### So sánh Code

**1. Phía Spring Boot:**
```java
@GetMapping("/users/{id}")
public ResponseEntity<User> getUserById(@PathVariable("id") Long id) {
    // Spring tự dùng Regex bóc tách {id} từ URL
    return ResponseEntity.ok(userService.findById(id));
}
```

**2. Phía Servlet Thuần:**
```java
@WebServlet("/api/users/*") // Cấu hình wildcard để đón tất cả URL con
public class PathVariableApiServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        resp.setContentType("application/json;charset=UTF-8");

        // Ví dụ URL: /api/users/1209
        // req.getServletPath() -> "/api/users"
        // req.getPathInfo()    -> "/1209"
        String pathInfo = req.getPathInfo();
        String userId = "unknown";
        
        if (pathInfo != null && pathInfo.length() > 1) {
            userId = pathInfo.substring(1); // Bỏ dấu gạch chéo đầu tiên
        }
        
        resp.getWriter().printf("{\"status\": \"success\", \"userId_extracted\": \"%s\"}", userId);
    }
}
```
