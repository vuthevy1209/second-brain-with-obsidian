### 1. Java Servlet là gì?


> [!NOTE] Note
> - Là Java class chạy trên Servlet Container (Tomcat).
> - Xử lý request từ client và trả về response.


- **Định nghĩa:** Là một thư viện/công nghệ của Java dùng để xây dựng các ứng dụng web (Web Applications) và hệ thống dịch vụ web.
- **Ứng dụng:** Đây là nền tảng cốt lõi (underlying infrastructure) để học các framework web Java cao hơn (như Java EE/Spring). Nó đặc biệt mạnh mẽ, chịu tải tốt, thường được dùng trong các hệ thống lớn như ngân hàng hoặc thương mại điện tử.
- **Lợi ích:** Cung cấp sẵn nhiều interface và class giúp lập trình viên tiết kiệm thời gian xây dựng nền tảng, tập trung vào logic nghiệp vụ và đảm bảo tính bảo mật.

### 2. Mô hình hoạt động của Web và Servlet

Để hiểu cách Servlet hoạt động, trước tiên cần hiểu quy trình cơ bản của một trang web:

1. **Client (Trình duyệt):** Gửi một yêu cầu (Request) thông qua URL tới máy chủ (Server).
2. **Server (Máy chủ):** Tiếp nhận, xử lý tài nguyên và trả về kết quả (Response) - có thể là trang HTML, file tải xuống, hình ảnh, v.v.
![[01. Giới thiệu-1786176149851.webp]]

**Mô hình hoạt động cụ thể của Servlet:**

- Khi có nhiều Request gửi đến cùng lúc, Server (như **Tomcat**) sẽ chuyển chúng cho môi trường chạy Servlet (Servlet Container/JVM).
- **<mark style="background:#affad1">Xử lý đa luồng (Multi-threading):</mark>** Khác với các hệ thống phải xếp hàng chờ đợi, <mark style="background:#affad1">Servlet tạo ra các luồng (threads) độc lập cho từng Request. Các Request được xử lý song song cùng lúc.</mark>
- **Tối ưu tài nguyên:**<mark style="background:#d3f8b6"> Servlet chỉ được khởi tạo **một lần duy nhất** khi Server khởi động</mark>. <mark style="background:#d3f8b6">Các Request sau đó chỉ việc sử dụng lại instance này để xử lý và trả về dữ liệu</mark>, giúp tiết kiệm thời gian và tài nguyên đáng kể.

### 3. Ưu điểm vượt trội của Java Servlet

- **Hiệu năng cao (Performance):** Nhờ cơ chế xử lý đa luồng (threads) cho từng request thay vì tạo process mới. 
- **Tính linh hoạt (Flexibility):** Dễ dàng mở rộng và tùy biến nhờ hệ sinh thái Java.
- **Mạnh mẽ (Robustness):** Được quản lý bởi máy ảo Java (JVM) với khả năng tự động quản lý bộ nhớ và thu gom rác (Garbage Collection).
- **Bảo mật cao (Security):** Kế thừa các tính năng bảo mật chặt chẽ của ngôn ngữ Java.

### 4. Các khái niệm cơ bản trong Web Development

Bài học cũng làm rõ một số thuật ngữ nền tảng:

- **Web tĩnh (Static Web):** Là trang web hiển thị nội dung HTML cố định, không thay đổi theo thời gian hoặc theo người dùng (trừ khi lập trình viên sửa trực tiếp file).
- **Web động (Dynamic Web):** Nội dung thay đổi liên tục dựa trên tương tác, cơ sở dữ liệu (Database) hoặc tài khoản đăng nhập (ví dụ: nội dung hiển thị sẽ khác nhau khi truyền vào các tham số khác nhau).
- **Giao thức HTTP (HTTP Protocol):** Là giao thức mạng tiêu chuẩn để Client và Server giao tiếp với nhau.
- **Request & Response:** * _Request:_ Yêu cầu từ Client gửi lên Server.
    - _Response:_ Kết quả Server trả về cho Client.
- **HTTP Methods:** Các phương thức gửi dữ liệu (như **GET, POST, PUT, DELETE**). Việc chọn phương thức nào sẽ quyết định cách dữ liệu được đóng gói và gửi đi.
- **Web Server:** Phần mềm chạy trên máy chủ để nhận Request và trả về Response, đồng thời quản lý tài nguyên web. (Ví dụ tiêu biểu trong Java là **Apache Tomcat**).
