# Xử lý Upload File trong Java Web

Tính năng người dùng tải Avatar, up CV lên Website... luôn là tính năng bắt buộc phải có.
Trong Servlet, quá trình xử lý Upload File đòi hỏi sự can thiệp của `MultipartConfig`.

---

### 1. Chuẩn bị ở phía HTML (Giao diện)
Để một Form HTML có thể đính kèm file đẩy lên mạng, bạn **BẮT BUỘC** phải gắn thêm thuộc tính `enctype="multipart/form-data"` vào thẻ `<form>`.

```html
<!-- NẾU QUÊN DÒNG ENCTYPE NÀY THÌ SERVLET SẼ KHÔNG NHẬN ĐƯỢC FILE! -->
<form action="/upload" method="POST" enctype="multipart/form-data">
    <label>Chọn ảnh đại diện:</label>
    <input type="file" name="avatar" accept="image/png, image/jpeg" required />
    
    <button type="submit">Tải lên</button>
</form>
```

---

### 2. Xử lý phía Server (Servlet)

Kể từ Java Servlet 3.0 trở đi, việc upload file đã dễ dàng hơn rất nhiều. Bạn chỉ cần gắn Annotation `@MultipartConfig` lên đầu class Servlet.

#### Ví dụ Code Upload chuẩn:
```java
@WebServlet("/upload")
@MultipartConfig(
    fileSizeThreshold = 1024 * 1024,      // 1 MB (Nếu file nhỏ hơn 1MB thì lưu vào RAM, bự hơn thì ghi tạm xuống ổ cứng)
    maxFileSize = 10 * 1024 * 1024,       // 10 MB (Kích thước tối đa của 1 file)
    maxRequestSize = 50 * 1024 * 1024     // 50 MB (Kích thước tối đa của toàn bộ Form)
)
public class UploadServlet extends HttpServlet {

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) 
            throws ServletException, IOException {
            
        // 1. Lấy ra cái File mà người dùng đính kèm từ Form (tên input là 'avatar')
        Part filePart = req.getPart("avatar");
        
        // 2. Lấy tên gốc của file
        String fileName = filePart.getSubmittedFileName();
        
        // 3. Đường dẫn lưu file trên Server (Ví dụ: Thư mục 'uploads')
        String uploadPath = getServletContext().getRealPath("/") + "uploads";
        File uploadDir = new File(uploadPath);
        if (!uploadDir.exists()) {
            uploadDir.mkdir(); // Tự động tạo thư mục nếu chưa có
        }
        
        // 4. Lưu file xuống đĩa cứng
        filePart.write(uploadPath + File.separator + fileName);
        
        // Trả về thông báo thành công
        resp.getWriter().print("Tải file thành công: " + fileName);
    }
}
```

---

> [!CAUTION] Cảnh báo Bảo mật (Security)
> Khi làm tính năng Upload, đừng ngây thơ lưu trực tiếp tên file gốc của người dùng:
> 1. Trùng tên file: `anh_the.jpg` của người A sẽ ghi đè lên `anh_the.jpg` của người B. Hãy chèn thêm Timestamp hoặc UUID vào tên file (`anh_the_1691234.jpg`).
> 2. Hack hệ thống (Path Traversal): Hacker truyền tên file là `../../../../etc/passwd` để bẻ khóa máy chủ. Hãy dùng hàm lấy tên chuẩn (`Paths.get(fileName).getFileName().toString()`) để cắt bỏ các ký tự `/`, `\`.
> 3. Tuyệt đối không cho phép Upload file đuôi `.exe`, `.sh`, `.jsp` lên Server. Mọi thứ có thể toang!
