# Kiến trúc MVC trong Java Web

![[12. Kiến trúc MVC-1786288129736.webp]]

MVC (Model - View - Controller) là kiến trúc thiết kế xương sống của hầu hết các Web Framework hiện đại (Spring MVC, Struts,...). 
Việc áp dụng MVC giúp code sạch sẽ, dễ bảo trì và tách biệt rõ ràng vai trò của từng thành phần.

- **Controller (Servlet):** Nhận request, điều hướng.
- **Service:** Xử lý nghiệp vụ.
- **DAO/Repository:** Truy cập database.
- **Model (Entity/DTO):** Lưu trữ dữ liệu.
- **View (JSP):** Hiển thị giao diện.

## 1. Ba thành phần của MVC

### M - Model (Mô hình Dữ liệu & Logic)
- **Bao gồm:** Các class Java thuần (JavaBeans/POJO), các class truy xuất Database (DAO).
- **Trách nhiệm:** Kết nối CSDL, xử lý logic nghiệp vụ (tính toán, validate chuyên sâu), và bọc dữ liệu lại.
- **Ví dụ:** Class `User.java`, `UserDAO.java`.

### V - View (Giao diện)
- **Bao gồm:** Các file `.jsp`, HTML, CSS, JavaScript.
- **Trách nhiệm:** Chỉ chuyên nhận dữ liệu từ Controller và hiển thị lên màn hình. **Tuyệt đối không** chứa logic tính toán kết nối Database ở đây.
- **Ví dụ:** File `index.jsp`, `profile.jsp`.

### C - Controller (Bộ điều khiển)
- **Bao gồm:** Các class Servlet (Kế thừa `HttpServlet`).
- **Trách nhiệm:** Đứng ở giữa làm cảnh sát giao thông.
  - Nhận Request từ người dùng (Vd: nhập form).
  - Lấy tham số (Parameters).
  - Gọi **Model** để xử lý hoặc lấy dữ liệu.
  - Nhận kết quả từ Model, gói vào Request (`setAttribute`).
  - Ném kết quả sang cho **View** hiển thị (bằng Forward hoặc Redirect).

## 3. Vai trò từng tầng và Code ví dụ

### Tầng 1: Model (Entity)
Chỉ chứa dữ liệu, **không** viết câu lệnh SQL, **không** viết HTML.

```java
public class User {
    private Long id;
    private String name;
    private String email;
    
    // Getter và Setter...
}
```

### Tầng 2: DAO (Data Access Object)
Chỉ làm việc với database, xử lý các thao tác CRUD.

**Interface:**
```java
public interface UserDAO {
    List<User> findAll();
    User findById(Long id);
    void save(User user);
}
```

**Implementation:**
```java
public class UserDAOImpl implements UserDAO {
    @Override
    public List<User> findAll() {
        // ... Viết code JDBC (Connection, Statement, ResultSet) ở đây ...
        return null;
    }
}
```

### Tầng 3: Service
Là nơi xử lý **nghiệp vụ cốt lõi** (Business Logic) như:
- Validate dữ liệu đầu vào.
- Mã hóa password.
- Tính toán phức tạp.
- Quản lý Transaction.
- Điều phối (gọi nhiều DAO cùng lúc).

```java
public interface UserService {
    List<User> getAllUsers();
}

public class UserServiceImpl implements UserService {
    private UserDAO userDAO = new UserDAOImpl();
    
    @Override
    public List<User> getAllUsers() {
        return userDAO.findAll();
    }
}
```

### Tầng 4: Controller (Servlet)
Đứng giữa tiếp nhận Request và trả về Response. Controller **không** viết SQL và **không** render HTML.

```java
@WebServlet("/users")
public class UserServlet extends HttpServlet {
    private UserService userService = new UserServiceImpl();
    
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        // 1. Gọi Service lấy dữ liệu
        List<User> users = userService.getAllUsers();
        
        // 2. Nhét dữ liệu vào Request
        req.setAttribute("users", users);
        
        // 3. Đá sang cho View hiển thị
        req.getRequestDispatcher("/views/user/list.jsp").forward(req, resp);
    }
}
```

### Tầng 5: View (JSP)
Chỉ chuyên lo việc hiển thị. Dùng JSTL + EL, **tuyệt đối tránh** dùng Scriptlet `<% %>`.

```jsp
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>

<h2>Danh sách User</h2>
<table>
    <c:forEach items="${users}" var="u">
        <tr>
            <td>${u.id}</td>
            <td>${u.name}</td>
            <td>${u.email}</td>
        </tr>
    </c:forEach>
</table>
```

---

> [!TIP] Tóm tắt nguyên tắc vàng
> - **JSP:** KHÔNG bao giờ viết code Java logic (`<% %>`), không kết nối DB. Chỉ hiển thị dữ liệu bằng EL/JSTL.
> - **Servlet:** KHÔNG bao giờ viết mã HTML bằng `out.print("<h1>")`. Chỉ điều hướng Request.
> - **Model:** KHÔNG quan tâm đến Giao diện web (Không có HttpServletRequest). Nó chỉ là các class Java thuần xử lý chuỗi, số, Database.
