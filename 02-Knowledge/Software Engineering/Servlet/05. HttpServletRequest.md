### 1. Tổng quan về HttpServletRequest

> [!NOTE] Định nghĩa cốt lõi
> `HttpServletRequest` là một Interface thuộc gói `jakarta.servlet.http` (hoặc `javax.servlet.http` ở bản cũ), đại diện cho **toàn bộ dữ liệu của HTTP Request** mà Client (Trình duyệt, Postman, Mobile App) gửi lên Server.

- **Cơ chế khởi tạo:** Khi có một request gửi tới, **Servlet Container (Tomcat)** sẽ <mark style="background:#affad1">tự động phân tích gói tin HTTP thô (Raw HTTP Request) và đóng gói vào đối tượng </mark>`HttpServletRequest`, sau đó truyền vào các hàm `service()`, `doGet()`, `doPost()`,...
- **Phạm vi (Scope):** Nằm trong **Request Scope** — Chỉ tồn tại trong suốt thời gian phục vụ 1 chu kỳ Request duy nhất. Khi Server hoàn tất trả Response về Client, đối tượng này sẽ bị giải phóng.

```
       [Client / Trình duyệt]
                 │
                 │ 1. Gửi HTTP Request (URL, Headers, Form Data, Body)
                 ▼
       ┌──────────────────┐
       │  Apache Tomcat   │ ──► Tạo đối tượng HttpServletRequest
       └────────┬─────────┘
                │
                │ 2. Truyền vào
                ▼
       ┌──────────────────┐
       │  HelloServlet    │ ──► doGet(HttpServletRequest req, HttpServletResponse resp)
       └──────────────────┘
```

### 2. Cấu trúc của một HTTP Request

Một gói tin HTTP Request gửi từ Client gồm 3 phần chính mà `HttpServletRequest` quản lý:

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. REQUEST LINE:  GET /learn_servlet/users?id=10 HTTP/1.1              │
├────────────────────────────────────────────────────────────────────────┤
│ 2. HEADERS:                                                            │
│    Host: localhost:8080                                                │
│    User-Agent: Mozilla/5.0 ...                                         │
│    Accept: application/json, text/html                                 │
│    Cookie: JSESSIONID=AB89F1234...                                     │
├────────────────────────────────────────────────────────────────────────┤
│ 3. BODY (Thường có trong POST / PUT):                                  │
│    username=admin&password=123 (Form Data) hoặc {"id": 10} (JSON)     │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. Các nhóm phương thức cốt lõi trong HttpServletRequest

#### 3.1. Nhóm 1: Lấy thông tin URL, URI và Giao thức

```java
// Giả sử request URL là: http://localhost:8080/learn-servlet/hello?name=John&age=20

String method      = req.getMethod();         // "GET" hoặc "POST"
String requestURI  = req.getRequestURI();     // "/learn-servlet/hello"
StringBuffer url   = req.getRequestURL();     // "http://localhost:8080/learn-servlet/hello"
String contextPath = req.getContextPath();    // "/learn-servlet" (Tên ứng dụng web)
String servletPath = req.getServletPath();    // "/hello" (Đường dẫn map tới Servlet)
String queryString = req.getQueryString();    // "name=John&age=20"
String protocol    = req.getProtocol();       // "HTTP/1.1"
```

#### 3.2. Nhóm 2: Lấy tham số dữ liệu gửi lên (Parameters)

<mark style="background:#affad1">Phương thức này dùng chung để lấy dữ liệu từ URL Query String (GET) hoặc Form Data (POST url-encoded):</mark>

```java
// 1. Cấu hình bảng mã tiếng Việt khi nhận Form POST
req.setCharacterEncoding("UTF-8");

// 2. Lấy giá trị của 1 tham số (Trả về null nếu không tồn tại)
String name = req.getParameter("name"); 

// 3. Lấy nhiều giá trị cùng tên (dùng cho checkbox, multiple select)
String[] hobbies = req.getParameterValues("hobbies"); 

// 4. Lấy toàn bộ tham số dưới dạng Map
Map<String, String[]> paramMap = req.getParameterMap();

// 5. Lấy danh sách tất cả các tên tham số
Enumeration<String> paramNames = req.getParameterNames();
```

> [!TIP] Đọc thêm bài viết chi tiết đối chiếu với Spring Boot
> Nếu bạn muốn xem bảng so sánh cách trích xuất dữ liệu giữa Servlet thuần và các Annotation trong Spring Boot (`@RequestParam`, `@PathVariable`, `@RequestBody`,...), hãy xem tại:
> 👉 [[Servlet vs Spring Boot]]

#### 3.3. Nhóm 3: Đọc Request Headers

```java
// Lấy giá trị của một Header bất kỳ
String userAgent = req.getHeader("User-Agent"); // Thông tin trình duyệt/OS của client
String authHeader = req.getHeader("Authorization"); // Token đăng nhập

// Lấy kiểu dữ liệu và kích thước của Request Body
String contentType = req.getContentType();      // "application/json" hoặc "multipart/form-data"
int contentLength  = req.getContentLength();
```

#### 3.4. Nhóm 4: Quản lý Thuộc tính (Request Attributes - Bộ nhớ Request Scope)

Dùng để lưu trữ và chia sẻ dữ liệu dạng **Object** trong cùng một chu kỳ Request:

```java
// 1. Cất dữ liệu vào Request Scope (Dạng Object)
req.setAttribute("userList", listUsers);
req.setAttribute("pageTitle", "Trang quản trị");

// 2. Lấy dữ liệu ra (Cần ép kiểu về class tương ứng)
List<User> users = (List<User>) req.getAttribute("userList");

// 3. Xóa thuộc tính khỏi Request
req.removeAttribute("pageTitle");
```

##### 💡 Các trường hợp sử dụng thực tế của `setAttribute()` & `getAttribute()`:
1. **Truyền Model sang View (JSP):** Servlet truy vấn CSDL xong, gắn `req.setAttribute("data", list)` rồi `forward` sang JSP để JSP dùng EL `${data}` hiển thị ra bảng HTML.
2. **Báo lỗi Form Validation:** Khi người dùng nhập sai, Servlet set `req.setAttribute("errorMessage", "Mật khẩu quá ngắn")` rồi forward lại form để hiển thị câu lỗi màu đỏ.
3. **Chia sẻ dữ liệu qua Filter (Middleware):** `AuthFilter` giải mã Token xong, gán `req.setAttribute("CURRENT_USER", user)` để các Servlet phía sau dùng lại mà không cần truy vấn lại CSDL.

#### 3.5. Nhóm 5: Điều hướng & Chuyển tiếp Request (`RequestDispatcher`)

```java
// 1. Chuyển tiếp (Forward) sang JSP/Servlet khác - URL trên trình duyệt KHÔNG đổi
RequestDispatcher dispatcher = req.getRequestDispatcher("/views/user-list.jsp");
dispatcher.forward(req, resp);

// 2. Nhúng nội dung trang khác vào trang hiện tại (Include)
req.getRequestDispatcher("/common/header.jsp").include(req, resp);
```

#### 3.6. Nhóm 6: Quản lý Session, Cookies và Thông tin Client

```java
// 1. Lấy hoặc tạo mới HttpSession
HttpSession session = req.getSession();       // Mặc định tương đương getSession(true)
HttpSession sessionExist = req.getSession(false); // Trả về null nếu session chưa tồn tại

// 2. Lấy danh sách Cookie gửi kèm từ Client
Cookie[] cookies = req.getCookies();

// 3. Lấy địa chỉ IP của Client
String clientIp = req.getRemoteAddr();
```

#### 3.7. Nhóm 7: Đọc dữ liệu Body lớn (JSON Payload / File Upload)

Khi Client gửi dữ liệu dạng **JSON (REST API)** hoặc Raw Text:

```java
// Đọc chuỗi JSON từ InputStream của Request bằng BufferedReader
StringBuilder jsonBuilder = new StringBuilder();
String line;
try (BufferedReader reader = req.getReader()) {
    while ((line = reader.readLine()) != null) {
        jsonBuilder.append(line);
    }
}
String requestBodyJson = jsonBuilder.toString();
```

### 4. Bảng phân biệt kinh điển: `getParameter()` vs `getAttribute()`

Đây là một trong những câu hỏi phỏng vấn phổ biến nhất về Servlet:

| Tiêu chí | `getParameter(String name)` | `getAttribute(String name)` |
| :--- | :--- | :--- |
| **Nguồn gốc dữ liệu** | Từ **Client gửi lên** (Query string trên URL hoặc Form body). | Do **Server (Servlet/Filter)** chủ động gán vào qua `setAttribute()`. |
| **Kiểu dữ liệu trả về** | Luôn là `String` (hoặc `String[]`). | Luôn là `Object` (Có thể lưu List, Map, DTO, Object bất kỳ). |
| **Khả năng chỉnh sửa** | **Chỉ đọc (Read-only)**, không thể sửa từ code Java. | **Đọc & Ghi (Read/Write)** thoải mái trên Server. |
| **Mục đích sử dụng** | Lấy input của người dùng (tên đăng nhập, mật khẩu, từ khóa tìm kiếm,...). | Truyền model dữ liệu từ Controller (Servlet) sang View (JSP) để hiển thị. |

### 5. Code minh họa tổng hợp

```java
package org.example.servlet;

import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;

@WebServlet("/submit-form")
public class FormHandlingServlet extends HttpServlet {

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) 
            throws ServletException, IOException {

        // 1. Cấu hình bảng mã tiếng Việt
        req.setCharacterEncoding("UTF-8");

        // 2. Lấy dữ liệu Form từ Client (Parameters)
        String fullName = req.getParameter("fullName");
        String email = req.getParameter("email");
        String[] skills = req.getParameterValues("skills");

        // 3. Xử lý logic nghiệp vụ
        String statusMessage = "Đăng ký thành công cho: " + fullName;

        // 4. Lưu dữ liệu vào Request Scope (Attributes) để gửi sang JSP hiển thị
        req.setAttribute("message", statusMessage);
        req.setAttribute("emailReceived", email);
        req.setAttribute("selectedSkills", skills);

        // 5. Chuyển tiếp (Forward) sang trang kết quả
        req.getRequestDispatcher("/result.jsp").forward(req, resp);
    }
}
```
