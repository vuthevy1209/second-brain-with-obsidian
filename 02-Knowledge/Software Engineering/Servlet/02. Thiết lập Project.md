### Bản chất Servlet

Là một **loại class Java đặc biệt**, dùng để xử lý request/response trong ứng dụng web, <mark style="background:#d3f8b6">chạy bên trong một **web container/server** (như Tomcat).</mark>

- **Mục đích:** nhận HTTP request từ client (trình duyệt), xử lý logic, rồi trả về HTTP response (thường là HTML, JSON...).
- **Ví dụ:** một class kế thừa `HttpServlet`, override phương thức `doGet()` để xử lý khi người dùng truy cập một URL cụ thể.
- **Cần chạy trong servlet container** (Tomcat, Jetty...) — không thể tự chạy như một chương trình Java thông thường.

- Chọn war và cấu hình <mark style="background:#d3f8b6">Application Context (base url)</mark>

## Cấu trúc thư mục

![[02. Thiết lập Project-1786179204975.webp]]

```
learn-servlet/
├── .idea/                           # Thư mục cấu hình riêng của IntelliJ IDEA (Run config, SDK, v.v.)
├── src/
│   └── main/
│       ├── java/                    # Nơi chứa toàn bộ mã nguồn Java (.java)
│       │   └── org/example/servlet/
│       │       └── HelloServlet.java # Lớp Servlet xử lý request & logic backend
│       ├── resources/               # Nơi chứa các file cấu hình (vd: application.properties, db.properties, v.v.)
│       └── webapp/                  # Thư mục gốc chứa giao diện và tài nguyên Web (public)
│           ├── index.jsp            # Trang chủ mặc định khi truy cập ứng dụng
│           ├── hello.jsp            # Trang view hiển thị kết quả từ Servlet gửi sang
│           └── WEB-INF/             # Thư mục BẢO MẬT đặc biệt của ứng dụng Java Web
│               └── web.xml          # File Deployment Descriptor cấu hình ứng dụng web
├── target/                          # Thư mục chứa kết quả build/compile (file .class, gói .war)
└── pom.xml                          # File cấu hình chính của Maven (quản lý dependencies, plugin)

```

### Chi tiết vai trò của từng thành phần quan trọng:

#### 1. pom.xml _(Project Object Model)_

- Quản lý các thư viện (dependencies) cần cho dự án, ví dụ: `jakarta.servlet-api`, `jakarta.servlet.jsp-api`.
- Cấu hình định dạng đóng gói `<packaging>war</packaging>` (Web Application Archive) để có thể deploy lên Tomcat.

#### 2. `src/main/java/` _(Tầng xử lý Backend)_

- Chứa toàn bộ các class Java: **Servlet** (điều hướng request), **Service** (nghiệp vụ), **DAO / Model** (dữ liệu).
- Ví dụ: HelloServlet.java lắng nghe request gửi tới URL `@WebServlet("/hello")`, xử lý và chuyển dữ liệu sang trang JSP.

#### 3. `src/main/webapp/` _(Tầng giao diện Web)_

- Là thư mục gốc chứa các file tĩnh và trang động mà trình duyệt có thể truy cập trực tiếp: HTML, JSP, CSS, JavaScript, hình ảnh (`/css`, `/js`, `/images`...).
- index.jsp: Trang chào đón mặc định khi người dùng vào URL gốc của ứng dụng.

#### 4. <mark style="background:#d3f8b6">`src/main/webapp/WEB-INF/` _(Thư mục bảo mật)_</mark>

- **Đặc điểm quan trọng:** Trình duyệt **KHÔNG THỂ** truy cập trực tiếp các file nằm trong `WEB-INF/` qua URL (ví dụ: gõ `http://localhost:8080/.../WEB-INF/...` sẽ bị chặn lỗi 404/403).
- Chỉ có mã nguồn Java bên trong Server (như Servlet) mới có quyền `forward` hoặc đọc file trong thư mục này. <font color="#8064a2"><mark style="background:#d3f8b6">Người ta thường đặt các trang JSP nội bộ hoặc file cấu hình quan trọng vào đây để tăng tính bảo mật.</mark></font>
- web.xml: File cấu hình ứng dụng Web (đăng ký filter, listener, session timeout, cấu hình mapping servlet dạng XML nếu không dùng annotation).

#### 5. `target/` _(Thư mục đầu ra)_

- Được Maven tự động tạo ra khi bạn build / chạy dự án.
- Chứa các file bytecode `.class` đã biên dịch và file đóng gói dạng `.war` để Tomcat tải và chạy. _(Thư mục này không cần commit lên Git)_.



#### HelloServlet

``` java
package org.example.servlet;  
  
import jakarta.servlet.ServletException;  
import jakarta.servlet.annotation.WebServlet;  
import jakarta.servlet.http.HttpServlet;  
import jakarta.servlet.http.HttpServletRequest;  
import jakarta.servlet.http.HttpServletResponse;  
  
import java.io.IOException;  
  
@WebServlet("/hello")  
public class HelloServlet extends HttpServlet {  
  
    @Override  
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)  
            throws ServletException, IOException {  
  
        req.setAttribute("message", "Hello từ Servlet!");  
  
        req.getRequestDispatcher("/hello.jsp")  
                .forward(req, resp);  
    }  
}
```

#### hello.jsp

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>  
<html>  
<head>  
    <title>Hello JSP</title>  
</head>  
<body>  
<h1>${message}</h1>  
<a href="index.jsp">Về trang chủ</a>  
</body>  
</html>
```


#### index.jsp

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>  
<html>  
<head>  
    <title>Servlet/JSP Learning</title>  
</head>  
<body>  
<h2>Học Servlet/JSP</h2>  
  
<ul>  
    <li><a href="hello">Hello Servlet -&gt; JSP</a></li>  
</ul>  
</body>  
</html>
```
