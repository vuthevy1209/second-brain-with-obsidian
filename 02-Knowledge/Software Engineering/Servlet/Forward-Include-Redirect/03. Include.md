# Bản chất của Include (Ghép nối HTML)

`include` giúp một trang web mượn giao diện hoặc dữ liệu của nhiều thành phần khác ghép lại thành một luồng (stream) duy nhất.

### 1. Include bằng Java Servlet (Đồng bộ)

- Các thành phần được gọi sẽ tuần tự đẩy mã HTML của chúng vào **cùng một Buffer**.
- Thường dùng làm Servlet điều phối (Controller lắp ráp Layout).

```java
@WebServlet("/demo-include")
public class IncludeDemoServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        resp.setContentType("text/html;charset=UTF-8");
        PrintWriter out = resp.getWriter();
        
        // 1. Ghép Header
        req.getRequestDispatcher("/common/header.jsp").include(req, resp);

        // 2. Tự sinh Body
        out.println("<h1>Nội dung do Servlet này tạo</h1>");

        // 3. Ghép Footer
        req.getRequestDispatcher("/common/footer.jsp").include(req, resp);
    }
}
```

### 2. Include trực tiếp trong JSP

Thay vì dùng Java, ta có 2 thẻ chèn Layout cực kỳ hữu dụng trong JSP:

| Tiêu chí | Thẻ Include Tĩnh (Static) | Thẻ Include Động (Dynamic) |
| :--- | :--- | :--- |
| **Cú pháp** | `<%@ include file="header.jsp" %>` | `<jsp:include page="header.jsp" />` |
| **Bản chất** | Lệnh **Copy & Paste** mã nguồn. | Tương đương `req.getRequestDispatcher().include()` |
| **Thời điểm chạy** | Lúc biên dịch (Translation Time). 2 file gom thành 1 hàm duy nhất. | Lúc đang chạy (Runtime). 2 file chạy độc lập. |
| **Nhược điểm** | Dễ bị lỗi trùng lặp tên biến cục bộ giữa cha và con. | Chậm hơn một chút (không đáng kể). |
| **Ưu điểm** | Siêu nhanh. | Độc lập biến, có thể truyền tham số qua `<jsp:param>`! |

> [!TIP] Lời khuyên
> Trong thực tế, luôn ưu tiên sử dụng thẻ Động `<jsp:include>` để tránh rắc rối về trùng tên biến.
