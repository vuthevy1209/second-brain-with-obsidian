# 03. IP Address (Địa chỉ IP)

## 1. Định nghĩa / Khái niệm cốt lõi
- **IP Address** là <mark style="background:#d3f8b6">địa chỉ logic định danh một thiết bị</mark> trên một mạng máy tính sử dụng giao thức Internet để giao tiếp.
- Giống như "địa chỉ nhà" giúp người đưa thư biết cần giao thư đến đâu. 

## 2. Cách thức hoạt động / Thành phần chính

### IPv4 và IPv6
- **IPv4:** Dài 32 bit, biểu diễn dưới dạng 4 cụm số thập phân (Ví dụ: `192.168.1.1`). Cung cấp khoảng 4.3 tỷ địa chỉ.
- **IPv6:** Dài 128 bit, biểu diễn dưới dạng Hex (Ví dụ: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`). Ra đời để giải quyết vấn đề cạn kiệt IPv4.

### Private IP vs Public IP
- <mark style="background:#b1ffff">Public IP (IP Công cộng):</mark> IP duy nhất trên toàn cầu (Internet), do ISP cung cấp. Các máy chủ (Server) trên Internet cần Public IP để mọi người truy cập.
- <mark style="background:#fdbfff">Private IP (IP Nội bộ):</mark> IP dùng trong mạng LAN, không định tuyến ra Internet. Gồm 3 dải chính:
  - `10.0.0.0` - `10.255.255.255`
  - `172.16.0.0` - `172.31.255.255`
  - `192.168.0.0` - `192.168.255.255`
- NAT (Network Address Translation) giúp nhiều thiết bị dùng chung Private IP có thể đi ra Internet thông qua 1 Public IP của Router.

### Subnetting & CIDR
- Subnet mask (Mặt nạ mạng) dùng để xác định phần nào là Network (mạng) và phần nào là Host (thiết bị). Ví dụ: `255.255.255.0`
- CIDR (Classless Inter-Domain Routing): Viết tắt subnet bằng dấu `/`. Ví dụ: `192.168.1.0/24` có nghĩa là 24 bit đầu tiên dành cho mạng.

## 3. Các công cụ / Lệnh thường dùng
- `ipconfig` (Windows) / `ifconfig` hoặc `ip a` (Linux): Xem địa chỉ IP hiện tại của máy.
- `curl ifconfig.me`: Lấy địa chỉ Public IP của máy qua command line.
- Cấu hình IP tĩnh: `/etc/network/interfaces` hoặc `/etc/netplan/` trên Ubuntu.
