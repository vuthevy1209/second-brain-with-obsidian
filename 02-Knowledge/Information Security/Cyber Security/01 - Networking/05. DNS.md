# 05. DNS (Domain Name System)

## 1. Định nghĩa / Khái niệm cốt lõi
- **DNS** là <mark style="background:#d3f8b6">hệ thống phân giải tên miền</mark>. Nó hoạt động như một danh bạ điện thoại của Internet, dịch tên miền dễ nhớ (như `google.com`) thành địa chỉ IP (như `142.250.190.46`) để máy tính hiểu.
- Hoạt động ở **Lớp 7 (Application)**, mặc định sử dụng port **UDP 53** cho query và **TCP 53** cho Zone Transfer.

## 2. Cách thức hoạt động / Thành phần chính

### Quá trình phân giải tên miền
Khi bạn gõ `google.com` vào trình duyệt:
1. **Trình duyệt (Browser Cache) & OS (Hosts file/OS Cache):** Kiểm tra xem đã biết IP này chưa. Nếu có thì trả về ngay.
2. **DNS Resolver (của ISP hoặc 8.8.8.8):** Máy bạn hỏi máy chủ DNS trung gian. 
3. **Root Server:** Nếu Resolver chưa biết, nó hỏi máy chủ gốc (Root `.`): "Ai giữ tên miền `.com`?"
4. **TLD Server (Top-Level Domain):** Root chỉ tới TLD `.com`. Resolver tiếp tục hỏi: "Ai giữ `google.com`?"
5. **Authoritative Name Server:** TLD chỉ tới máy chủ quản lý `google.com`. Máy chủ này trả về địa chỉ IP chính xác cho Resolver.

### Các loại DNS Records (Bản ghi DNS)
- `A Record`: Trỏ tên miền (IPv4). Ví dụ: `example.com -> 1.2.3.4`
- `AAAA Record`: Trỏ tên miền (IPv6).
- `CNAME (Canonical Name)`: Trỏ tên miền phụ sang tên miền chính. Ví dụ: `www.example.com -> example.com`
- `MX (Mail Exchanger)`: Trỏ đến máy chủ Email.
- `TXT Record`: Chứa văn bản xác thực, thường dùng cho SPF, DKIM (bảo mật email).

## 3. Các công cụ / Lệnh thường dùng
- `nslookup`: Công cụ có sẵn trên cả Windows/Linux để tra cứu DNS.
- `dig`: Công cụ mạnh mẽ hơn (thường trên Linux) để truy vấn thông tin DNS chi tiết (Ví dụ: `dig google.com`).
- `host`: Lệnh cơ bản tra cứu IP từ tên miền.
- **Tấn công:** DNS Enumeration (Dùng Nmap, dnsenum, hoặc Zone Transfer `dig axfr`).
