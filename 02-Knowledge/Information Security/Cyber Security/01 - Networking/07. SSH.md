# 07. SSH (Secure Shell)

## 1. Định nghĩa / Khái niệm cốt lõi
- **SSH** là giao thức mạng dùng để <mark style="background:#d3f8b6">đăng nhập và thực thi lệnh từ xa một cách an toàn</mark> trên các hệ thống Linux/Unix. 
- Mọi dữ liệu (bao gồm thông tin đăng nhập và command) đều được mã hóa (khác với Telnet gửi plain-text).
- Chạy trên port mặc định **TCP 22**.

## 2. Cách thức hoạt động / Thành phần chính

### Xác thực SSH
Có 2 cách xác thực phổ biến:
1. **Password Authentication:** Nhập Username và Password. Rủi ro bị tấn công Brute-force.
2. **Public Key Authentication (Khuyên dùng):** 
   - Sinh ra 1 cặp khóa (Public Key và Private Key).
   - Đưa **Public Key** lên máy Server (vào file `~/.ssh/authorized_keys`).
   - Giữ **Private Key** ở máy cá nhân. Khi đăng nhập, nếu khớp khóa, Server sẽ cho phép truy cập mà không cần nhập mật khẩu.

### Tunneling & Port Forwarding
SSH không chỉ dùng để chạy lệnh, nó còn có thể tạo đường hầm (Tunnel) bảo mật để bypass tường lửa hoặc forward port:
- **Local Port Forwarding:** Truy cập một dịch vụ Local của Server từ máy Client thông qua SSH.
- **Dynamic Port Forwarding:** Biến máy chủ SSH thành một SOCKS Proxy (để ẩn danh lưu lượng web).

## 3. Các công cụ / Lệnh thường dùng
- `ssh user@ip_address`: Đăng nhập cơ bản.
- `ssh -i private_key.pem user@ip`: Đăng nhập bằng Private Key (Thường dùng cho AWS/Cloud).
- `ssh-keygen`: Sinh cặp khóa RSA/Ed25519.
- `scp file.txt user@ip:/path/`: Lệnh copy file qua SSH một cách bảo mật.
- `hydra -l root -P passwords.txt ssh://ip_address`: Công cụ bẻ khóa mật khẩu SSH (Pentesting).
