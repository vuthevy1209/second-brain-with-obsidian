# 02. TCP/IP Model (Transmission Control Protocol / Internet Protocol)

## 1. Định nghĩa / Khái niệm cốt lõi
- **Mô hình TCP/IP** là <mark style="background:#d3f8b6">mô hình thực tế</mark> được sử dụng rộng rãi nhất trên Internet, tinh gọn hơn so với mô hình OSI.
- Mô hình này tập trung vào 2 giao thức cốt lõi là **TCP** (đảm bảo độ tin cậy) và **IP** (đảm bảo định tuyến địa chỉ).

## 2. Cách thức hoạt động / 4 Lớp trong TCP/IP

Khác với OSI (7 lớp), TCP/IP thường được mô tả với 4 lớp:

- **Lớp 4 - Application (Ứng dụng):** Tương đương với lớp 5, 6, 7 của OSI. Các giao thức: HTTP, HTTPS, SSH, FTP, DNS.
- **Lớp 3 - Transport (Giao vận):** Tương đương lớp 4 của OSI. Giao thức cốt lõi: 
  - <mark style="background:#fdbfff">TCP</mark>: Tin cậy, có xác nhận (Three-way Handshake), không mất gói tin (Web, Email, SSH).
  - <mark style="background:#affad1">UDP</mark>: Không tin cậy, không chờ xác nhận, tốc độ nhanh (Game online, Streaming, DNS).
- **Lớp 2 - Internet (Mạng):** Tương đương lớp 3 của OSI. Giao thức cốt lõi: IP (IPv4, IPv6), ICMP, ARP. Xử lý việc tìm đường (Routing).
- **Lớp 1 - Network Access (Truy cập Mạng):** Tương đương lớp 1, 2 của OSI. Giao thức phần cứng: Ethernet, Wi-Fi, MAC, cáp mạng.

### Bắt tay 3 bước của TCP (Three-way Handshake)
Để thiết lập kết nối tin cậy, TCP phải thực hiện 3 bước:
1. `SYN`: Client gửi yêu cầu kết nối đến Server.
2. `SYN-ACK`: Server đồng ý kết nối và phản hồi lại Client.
3. `ACK`: Client xác nhận lại việc nhận phản hồi. Lúc này kết nối được mở.

## 3. Các công cụ / Lệnh thường dùng
- `netstat`: Kiểm tra các kết nối TCP/UDP đang mở trên máy (Ví dụ: `netstat -ano` trên Windows hoặc `netstat -tulpn` trên Linux).
- `nc (Netcat)`: Đọc/Ghi dữ liệu qua kết nối TCP/UDP (thường dùng trong hacking/pentest).
- `tcpdump`: Lệnh bắt gói tin TCP/IP phổ biến trên môi trường CLI Linux.
